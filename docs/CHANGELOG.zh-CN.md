## 2.1.327

**✨ 本版亮点**

- 🚀 **新功能**：新增 claude mcp add-json 从 stdin 读取服务器配置，令牌不再出现在命令行中
- 🚀 **新功能**：/status 现在集中列出损坏的 agent、技能、命令文件及失效的权限设置等问题
