# Claude Code v2.0.12 更新日志

> 🗓 2025-10-09 发布 · 📋 11 条更新（🔧 1 · 🔄 1 · 📌 9）

**✨ 本版亮点**

- 🚀 **新功能**：插件系统正式发布，可通过自定义命令、agents、hooks 和 MCP 服务器扩展 Claude Code
- 🚀 **新功能**：新增 /plugin 系列命令，支持安装、启用/禁用插件及管理插件市场
- 🚀 **新功能**：支持仓库级插件配置，便于团队协作共享插件市场
- 🔧 **改进**：/doctor 命令提供更全面的错误信息与诊断
- 🐛 **关键修复**：/config 中的 verbose 设置现可跨会话持久保存
