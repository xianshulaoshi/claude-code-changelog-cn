# Claude Code v2.1.222 更新日志

> 🗓 2026-08-04 发布 · 📋 21 条更新（🔧 3 · 🔄 2 · 🐛 16）

**✨ 本版亮点**

- 🐛 **关键修复**：修复 worktree 隔离会话可对主检出执行破坏性 git 命令的安全问题，隔离现覆盖所有会话类型
- 🐛 **关键修复**：修复 HTTPS 代理后启动连接检查挂起失败，现使用代理感知传输并超时提示明确
- 🔧 **改进**：auto 模式下 SendMessage 发往其他会话的消息先经权限分类器评估，安全性提升
- 🐛 **关键修复**：修复 /usage 将后续所有回合都归因于 MCP 服务器，用量统计更准确
- 🔧 **改进**：Remote Control 不再可被仓库本地设置开启，仅能通过用户级 /config 启用

**📋 更新明细**（共 21 条，按类别归组）

**🔧 改进**（3 条）

- 改进 auto 模式安全性：通过 `SendMessage` 发往其他 agent 会话的消息现在会在发送前由权限分类器评估
- 改进 Claude 尝试调用带 `disable-model-invocation` 的 skill 时的拒绝行为：现在会告知 Claude 请你手动运行该 skill，而非复制其工作流
- 改进 `/diff` 视图、Remote Control 工作区 diff 以及 Claude Code on the web 会话中的文件编辑 diff，改用原始 git blob 内容，忽略工作区配置的 diff 驱动和 textconv

**🔄 变更**（2 条）

- 变更 Remote Control 自动启动逻辑：仓库本地设置（`.claude/settings.json` 或 `.claude/settings.local.json`）不再能开启它（仍可关闭）；请通过用户级 `/config` 启用
- 移除 ultraplan 功能

**🐛 修复**（16 条）

- 修复 worktree 隔离会话及其 subagent 可对主检出执行破坏性 git 命令的问题；隔离现在适用于所有会话类型的文件编辑和 Bash
- 修复 PreToolUse 自动放行 hook 在后台 agent 任务（摘要、压缩、重命名）中绕过工具限制的问题
- 修复 Team 和 Enterprise 版的 `/usage-credits` 对早前请求已被驳回的成员显示“你已发送过用量积分请求”，导致其无法再次发送
- 修复 HTTPS 代理环境下启动连接检查挂起后失败的问题；现在使用与 API 请求相同的代理感知传输，超时会给出明确提示
- 修复在实际已成功完成的响应上报告 "Connection closed mid-response" 错误的问题
- 修复 `/usage` 过度归因于 MCP 服务器的问题：服务器的占比现在仅反映实际消耗其工具结果的请求，而非调用后所有回合
- 修复会话无法关联分支推送后创建的 pull request 的问题，包括通过 GitHub REST API 创建的情况
- 修复组织受限的 `model: opus` 类 subagent 与 teammate 家族别名回退到父模型的问题，现会降级到家族中组织允许的最新模型
- 修复自定义 `ANTHROPIC_BASE_URL` 网关上即使服务器 keep-alive ping 正常到达仍触发流式空闲超时的问题
- 修复 claude.ai 连接器在会话令牌失效时被错误标记为需要授权的问题，现会改为显示 `/login` 提示
- 修复本地已不可用的工具（例如 MCP 服务器被移除后）的工具错误不显示的问题
- 修复 `SendMessage` 因摘要过长而被拒绝的问题，现在会截断，发送不再因字符数上限失败
- 修复 subagent 转录视图中 spinner 的 effort 标签显示会话 effort 级别而非 subagent 自身 `effort:` 设置的问题
- 修复文件监视器遇到文件系统错误或在销毁时偶发的崩溃
- 修复 `--ax-screen-reader` 模式下屏幕阅读器在每次退格时重读整行输入的问题，行尾删除现在只回显被删除的字符
- 修复设置 `CLAUDE_CODE_PROVIDER_MANAGED_BY_HOST` 时主机模型选择键未优先于磁盘上过期的 `managed-settings.json` 的问题
