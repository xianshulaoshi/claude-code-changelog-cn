# Claude Code v2.1.210 更新日志

> 🗓 2026-07-14 发布 · 📋 33 条更新（🚀 2 · 🔧 7 · 🐛 22 · 📌 2）

**✨ 本版亮点**

- 🐛 **关键修复**：修复 isolation: 'worktree' 子代理误在主仓库执行 git 写操作，隔离更安全
- 🔧 **改进**：折叠工具摘要新增实时计时器，长任务不再看起来像卡死
- 🐛 **关键修复**：修复 claude attach 在会话切换时报 job not found 等错误，连接更稳定
- ⭐ **亮点**：加固 Agent 工具，防御子代理读取内容中的间接提示注入
- 🔧 **改进**：auto 权限分类器外部会话默认使用 Sonnet 5，授权判断更精准

**📋 更新明细**（共 33 条，按类别归组）

**🚀 新功能**（2 条）

- 在折叠的工具摘要行中添加了实时耗时计时器，长时间运行的工具调用会持续跳动显示，不再看起来像卡住
- 为 `Write(path)`、`NotebookEdit(path)` 和 `Glob(path)` 权限规则添加了启动警告——请改用 `Edit(path)` 或 `Read(path)`

**🔧 改进**（7 条）

- 加固了 Agent 工具，防御子代理所读取内容中的间接提示注入
- 改进了 Bash/PowerShell 工具在命令超时并自动转入后台时的提示消息，使模型能够区分卡死与显式的后台请求
- 改进 auto 模式：权限分类器在外部会话中现在默认使用 Sonnet 5，在会话首次请求时验证并在会话内固定
- 改进内置 dataviz skill 的图表颜色校验，采用感知层面的 OKLab 色差并重新校准了色盲阈值
- 导致 MEMORY.md 索引超出读取限制的内存写入现在会产生明确的错误，而非静默截断
- 屏幕阅读器模式现在会在使用 Shift+Tab 切换权限模式时语音播报模式变更
- 代理视图底部提示现在会显示有多少后台代理正在等待你的输入，且数量变化时会有短暂的颜色强调

**🐛 修复**（22 条）

- 修复 `isolation: 'worktree'` 子代理能够在主仓库检出上运行会改变 git 状态的命令，而非其自身隔离工作树的问题
- 修复 `ultracode` 关键词触发会因非人类来源的输入（如 webhook 载荷和转发的 PR 评论）而误触发的问题
- 修复当 UI 组件在带样式的文本元素之外返回内容时，渲染的文本片段会泄漏到崩溃遥测中的问题
- 修复粘贴标记泄漏到从 Claude Code 打开的外部编辑器中，可能在粘贴文本周围显示多余的 È/É 字符的问题
- 修复 `claude attach` 在会话切换期间偶尔报 "job not found" 或 "agent is still starting" 错误——attach 现在会等待守护进程就绪，且慢速 attach 期间的终端尺寸调整会在完成后一次性应用
- 修复当工具的结果渲染器返回数值 bigint 或纯文本而非 UI 元素时导致会话崩溃的问题
- 修复 hook 回调超时被误报给模型为用户拒绝，导致无人值守会话停止并等待的问题
- 修复 Claude 在 `cd` 命令被移至后台后仍认为其已生效的问题——工具结果现在会明确说明工作目录未改变
- 修复插件提供的 MCP 服务器在会话中途重新同步 MCP 服务器时被意外关闭的问题
- 修复未经编辑的计划审批被标记为 "(edited by user)" 并用过期快照覆盖计划文件的问题
- 修复 `/doctor` 在 Bedrock、Vertex 和 Foundry 上跳过 auto 模式默认值建议的问题，这些平台上 auto 模式已无需手动开启
- 修复 Grep 内容模式在翻页超出结果末尾时错误显示 "No matches found" 的问题
- 修复 skills 和命令中未匹配的 `$1`/`$2` 位置占位符被静默剥离的问题——现在会原样保留
- 修复插件缓存写入失败时残留临时文件，以及在 Windows 和网络文件系统上因文件锁定导致重命名失败的问题
- 修复客户端重置与后台服务的连接时后台 worker 崩溃循环的问题
- 修复 `claude agents --effort ultracode` 无法传递到派发会话——该值被静默丢弃的问题
- 修复按 ← 打开代理视图后返回会话时丢失任务追踪器的问题
- 修复代理仪表盘在会话删除后仍保留来自已放弃回复草稿的粘贴图片的问题
- 修复被终止的后台会话遗留永久性 `git worktree lock` 的问题——定期清理现在会释放所属进程已不存在的锁
- 修复通过 `initialize` 控制请求注册的 SDK MCP 服务器要等到下一轮才开始连接的问题
- 修复在 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 下从会话返回代理视图时出现重叠的残影帧的问题
- 修复较晚出现的 `.claude/*` 符号链接未被纳入沙箱写入拒绝列表的问题

**📌 其他**（2 条）

- 代理视图：即使鼠标悬停或方向键移动了选中项，你按 ← 离开的会话仍保持可见标记
- 在修复导致 Fable advisor 故障的服务端问题期间，Fable 在 advisor 选择器中暂时显示为不可用
