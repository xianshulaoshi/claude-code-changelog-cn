# Claude Code v1.0.61 更新日志

> 🗓 2025-07-25 发布 · 📋 8 条更新（🚀 4 · 🔄 1 · 🐛 3）

**✨ 本版亮点**

- 🚀 **新功能**：新增 `--settings` 标志，可从 JSON 文件加载配置
- 🚀 **新功能**：VSCode macOS 支持用 ⌘+V 粘贴图片
- 🚀 **新功能**：新增 `CLAUDE_CODE_SHELL_PREFIX` 环境变量，可包装 Claude 执行的 shell 命令
- 🔧 **改进**：Transcript 模式改为按 Esc 退出，不再误触中断
- 🐛 **关键修复**：修复斜杠命令 allowed-tools 搭配 Bash 时的权限校验问题
