# Claude Code v2.1.132 更新日志

> 🗓 2026-05-06 发布 · 📋 28 条更新（🚀 3 · 🔧 2 · 🐛 23）

**✨ 本版亮点**

- 🚀 **新功能**：新增 CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1，可退出全屏渲染，保留终端原生滚动回看对话
- 🐛 **关键修复**：修复外部 SIGINT（IDE 停止按钮等）导致异常退出，现可优雅关闭并提示 --resume
- 🐛 **关键修复**：修复 stdio MCP 服务器向 stdout 写入非协议数据导致内存无限增长（10GB+ RSS）的问题
- 🐛 **关键修复**：修复 Cursor 与 VS Code 鼠标滚轮过快、JetBrains 2025.2 滚轮误触发方向键等集成终端问题
- 🐛 **关键修复**：修复 --resume 因表情符号被截断报错 no low surrogate in string，旧损坏会话加载时自动清理

**📋 更新明细**（共 28 条，按类别归组）

**🚀 新功能**（3 条）

- 在 Bash 工具子进程环境中新增 `CLAUDE_CODE_SESSION_ID` 环境变量，与传递给 hooks 的 `session_id` 保持一致
- 新增 `CLAUDE_CODE_DISABLE_ALTERNATE_SCREEN=1` 环境变量，可选择退出全屏备用屏幕渲染器，将对话保留在终端原生滚动缓冲区中
- 新增 "Pasting…" 底部提示，在读取剪贴板中的 Ctrl+V 粘贴图片时显示

**🔧 改进**（2 条）

- 改进斜杠命令对话框以及 `/login`、`/upgrade`、`/extra-usage` 对话框间距的视觉一致性
- 更新 `/tui fullscreen` 启动横幅，补充说明渲染器的更多优势（更低内存占用、鼠标支持、选中即复制）

**🐛 修复**（23 条）

- 修复外部 SIGINT（如 IDE 停止按钮、`kill -INT`）不会触发优雅关闭的问题——现在会恢复终端模式并打印 `--resume` 提示，而非突然退出
- 修复原生构建下会话中途关闭终端或 SSH 断开连接时出现未捕获异常的问题
- 修复 `--resume` 在工具错误截断拆分 emoji 时报错 `no low surrogate in string` 的问题；已损坏的旧会话在加载时会自动清理
- 修复使用 `-p --continue`/`--resume` 恢复计划模式会话时 `--permission-mode` 标志被忽略的问题，以及同一会话内 `ExitPlanMode` 后计划模式未被重新应用的问题
- 修复全屏模式在笔记本睡眠/唤醒或 Ctrl+Z/`fg` 后显示空白屏幕，直到下一次按键或流式输出才恢复的问题
- 修复当印度语合体字符或 ZWJ emoji 跨行换行时，Ctrl+E/A/K/U/方向键使光标落在字素中间的问题
- 修复 vim 操作符破坏包含分解式（NFD）重音字符文本的问题
- 修复粘贴以 `/` 开头的文本时输入被静默吞掉或触发未知命令回复的问题
- 修复焦点事件或鼠标追踪报告与括号粘贴交错时，杂散转义序列被倾倒进输入框的问题
- 修复 Cursor 和 VS Code 1.92–1.104 中由于上游 xterm.js bug 导致鼠标滚轮滚动过快的问题
- 修复 JetBrains IDE 2025.2 终端中的滚轮处理问题（误触发方向键、方向颠倒、滚动加速失控）
- 修复 Linux/X11 上 `/usage` 中 Ctrl+S 将统计截图复制到剪贴板时挂起的问题
- 修复 `/terminal-setup` 在 Windows Terminal 中显示矛盾错误的问题——该终端原生支持 Shift+Enter
- 修复 `/effort` 选择器未反映 `CLAUDE_CODE_EFFORT_LEVEL` 环境变量覆盖的问题
- 修复 `/status` 对部分用户显示错误默认模型的问题
- 修复斜杠命令自动补全弹窗最多只显示约 3–5 条命令的问题，现在会随终端高度自适应扩展
- 修复 statusline 中 `context_window` token 计数反映的是会话累计总量而非当前上下文使用量的问题
- 修复 macOS 终端（iTerm2、Terminal.app 默认设置）未启用 "Option as Meta" 时 Alt+T（thinking 开关）不生效的问题
- 修复 Windows 上从 `claude agents` 重新打开后台会话后键盘输入失效的问题
- 修复 stdio MCP 服务器向 stdout 写入非协议数据时内存无限增长（RSS 超过 10GB）的问题
- 修复 MCP 服务器连接成功但 `tools/list` 失败时静默显示 0 个工具的问题——现在会重试一次，并在 `/mcp` 中显示 "connected · tools fetch failed"
- 修复未授权的 claude.ai MCP 连接器显示为 "failed" 而非 "needs auth" 的问题，并修复 headless `-p` 模式重试非临时性 4xx 连接失败的问题
- 修复设置 `ENABLE_PROMPT_CACHING_1H` 时 Bedrock 和 Vertex 出现 400 错误的问题
