**📋 更新明细**（共 39 条，按类别归组）

**🚀 新功能**（3 条）

- 新增 `/config key=value` 语法，可在提示符中直接设置任意配置项（例如 `/config thinking=false`），在交互模式、`-p` 和 Remote Control 中均可用
- 新增 `sandbox.allowAppleEvents` 可选设置，允许沙箱中的命令在 macOS 上发送 Apple Events
- 新增 `CLAUDE_CLIENT_PRESENCE_FILE` 环境变量：指向一个标记文件，当你正在电脑前时可抑制移动端推送通知

**🔧 改进**（5 条）

- 将内置的 Bun 运行时升级到 1.4
- 改进长段落流式输出：文本现在逐行显示，不再等待首个换行符才出现
- 改进自动重试：思考过程中 API 连接断开现在会自动重试，不再显示 "Connection closed while thinking"
- 改进子代理面板：空闲子代理 30 秒后自动隐藏，列表最多显示 5 行并带滚动提示，键盘提示现在显示在底部栏
- 改进 MCP OAuth 浏览器页面，与 Claude Code 的视觉风格保持一致，并在授权成功后自动关闭

**🔄 变更**（2 条）

- 调整全屏模式下打开 URL 需 Cmd+点击（macOS）/ Ctrl+点击，与原生终端行为保持一致
- 调整 `Improved N memories` 一行，在非详细模式下不再列出各个文件

**🐛 修复**（29 条）

- 修复自定义 `ANTHROPIC_BASE_URL` 以及 Foundry 上提示词缓存无法读取的问题，原因是每轮请求的 attestation token 都在变化
- 修复 Write/Edit 在网络驱动器和云同步文件夹中生成 0 字节或截断文件的问题
- 修复 macOS 上 `open`、`osascript` 和基于浏览器的认证流程报错 -600 的问题，方法是添加 Apple Events entitlement
- 修复一个启动回归问题（全新环境下每次启动约慢 120ms，由 2.1.169 引入）：未配置 MCP 服务器时，首个提示不再等待托管设置的拉取
- 修复网络降级时账户设置拉取缓慢导致启动阻塞、终端空白长达 15 秒的问题
- 修复 `.claude.json` 中包含损坏的 null 项目条目时的启动崩溃（`TypeError: Cannot read properties of null`）
- 修复 macOS 上 Spotlight 忙于重建索引时 TUI 在会话开始时冻结（Ctrl+C 无响应）的问题
- 修复长时间空闲的会话在另一个 Claude Code 进程执行 30 天转录清理时丢失历史记录的问题
- 修复前台子代理无限生成嵌套链的问题；现在与后台子代理一样遵循 5 层深度限制
- 修复 `/recap` 和对话分叉在切换模型后立即仍使用旧模型的问题
- 修复子代理 "Thinking" 时长显示的是父代理的耗时而非子代理自身耗时的问题
- 修复被嵌套代理阻塞的子代理在代理面板中显示不断跳动的计时而非 "waiting" 的问题
- 修复 API 重试指示器（"Retrying in 0s · attempt N/10"）在重试成功后仍停留在屏幕上的问题
- 修复 AWS `awsCredentialExport` 凭证剩余有效期较短导致每分钟刷新一次凭证的问题，现在也支持 `aws configure export-credentials` 的 JSON 格式
- 修复 `claude mcp get`/`list` 在 tools/list 失败时仍显示 `✓ Connected` 的问题；现在会显示 `! Connected · tools fetch failed` 及错误详情
- 修复 `/remote-control` 残留一行过期的 "connecting…" 的问题；连接成功后现在会在转录中确认
- 修复 Windows 上无法解析裸 `git` 命令时，ExitWorktree 拒绝移除干净 worktree 并报 "Could not verify worktree state" 的问题
- 修复 `~/.claude/settings.json` 是符号链接的 `~/.claude` 下的相对符号链接时，修改设置（如 `/effort` 或 `/model`）报 ENOENT 失败的问题
- 修复上下文提醒中 IDE 选区行号偏移一行的问题（IntelliJ 和 VS Code）
- 修复全屏模式下进行原生终端选区（modifier+拖拽）后按 Ctrl+C 会用应用先前的选区覆盖剪贴板的问题
- 修复剪贴板中包含文本时 Ctrl+V 显示 "No image found in clipboard" 而非执行粘贴的问题
- 修复 agents 目录已存在时（Windows/OneDrive）代理创建报 "EEXIST: file already exists" 失败的问题
- 修复 AskUserQuestion 预览内容在对话框边缘被截断而非自动换行的问题
- 修复 AskUserQuestion 多选题提交时静默丢弃已输入的 "Other" 自由文本答案的问题
- 修复 `/stats` 的 "Most active day" 和每日 token 图表日期在 UTC 负时区显示提前一天的问题
- 修复 Linux 上 Claude Code 启动后安装的剪贴板工具无法被 `/copy` 和选中即复制检测到的问题
- 修复 Write（创建文件）预览中 Tab 缩进代码缩进渲染错误的问题
- 修复对话转录中轮次期间排队的用户提示未显示全宽背景高亮的问题
- 修复 Ghostty 中活动加载动画的脉冲停留在错误字符尺寸的问题
