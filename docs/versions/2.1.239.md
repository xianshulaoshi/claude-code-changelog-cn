# Claude Code v2.1.239 更新日志

> 🗓 2026-08-21 发布 · 📋 59 条更新（🚀 2 · 🔧 17 · 🐛 38 · 📌 2）

**✨ 本版亮点**

- 🐛 **关键修复**：修复 Bedrock 代理剥离 Content-Type 时流式静默降级，导致每轮对话重复计费的问题
- 🔧 **改进**：成本估算（/cost、状态栏、--max-budget-usd）计入数据驻留工作区的 1.1 倍美国推理溢价
- 🚀 **新功能**：新增 /claude-api upgrade 命令，一键将 Python 项目从 anthropic 0.x 迁移到 1.x
- 🐛 **关键修复**：修复 JetBrains 终端中 Edit/Write 调用被暂停约 5 秒的问题
- 🚀 **新功能**：Windows 支持跨会话消息互通，SendMessage 与 ListAgents 可跨机器查找并通信

**📋 更新明细**（共 59 条，按类别归组）

**🚀 新功能**（2 条）

- 在 Bedrock、Vertex、Foundry 等此前不支持的环境中加入了一次性全屏渲染器提示；这些环境的新安装现在默认以全屏模式启动
- 新增 `/claude-api upgrade` 命令，用于将 Python 项目从 `anthropic` 0.x 迁移到 1.x，并更新了该技能的 Python 参考以适配 1.x（超时使用 `anthropic.Timeout`，而非 `httpx.Timeout`）

**🔧 改进**（17 条）

- 成本估算（`/cost`、状态栏、`--max-budget-usd`）现在计入数据驻留工作区的 1.1× 仅美国推理溢价
- 云端会话：从 claude.ai 同步的插件现在显示为 `name@synced`，可通过 `claude plugin enable/disable <name>@synced` 操作，且不会覆盖你本地已安装的同名插件
- Alpine/musl 构建：原生图片粘贴、剪贴板和音频采集附加组件现在可以加载（改用 musl 编译的二进制文件，不再被运行时拒绝加载 glibc 版本）
- 当月支出限额已用尽时显示的用量限制提示，现在也会告知会话或每周限额何时重置
- 改进了压缩后显示的提醒，避免技能的原始参数被作为新请求重新执行
- 工具使用行的长文件路径现在从中间截断，保持单行显示
- `/goal`：对长时间运行的后台任务的重复签到现在会退避（30 分钟，然后 1 小时，之后每 2 小时），而不是每 30 分钟重复一次
- `/goal`：通过 `claude --resume` 选择器恢复会话时，现在会恢复其活跃的 goal
- `ListAgents` 现在会告知会话自身的名称（即同伴向其发消息时使用的名称），向自己的名称发送 `SendMessage` 会明确提示，而不是报 "no agent named …"
- `ListAgents` 和 `/list-agents` 现在会列出你的活跃同伴（此前仅显示 subagents 和其他会话，导致可访问的同伴看似不存在）
- `keybindingFlavor: "readline"` 现在也对 Bash 的单词键生效：Alt+F 和 Ctrl/Option+→ 停在单词末尾，Alt+D 删除到该处（Ctrl+Y 可粘贴回来），标点符号分隔单词
- 持久重试模式（`CLAUDE_CODE_RETRY_WATCHDOG``）现在在遇到组织支出限额和额度耗尽错误时立即失败，而不是无限等待重置
- Claude in Chrome：`/clear` 现在会关闭会话的 Chrome 标签组，空标签组也会在 `/resume` 和 Claude Code 退出时关闭
- 远程会话：从移动端上传的图片现在包含其保存的文件路径，Claude 可以将其复制到自己创建的文件中
- Claude Code 网页版：Bash 等工具对非 API 的 anthropic.com 主机（如 www、docs）的请求现在会经过会话的网络代理，因此你环境的允许域名规则同样适用
- Windows：跨会话消息功能现已可用，你的各机器上的 Claude Code 会话可以通过 `SendMessage` 互相发消息，并通过 `ListAgents` 互相发现，与 macOS 和 Linux 一致
- [VSCode] 用量限制横幅中的 "View usage" 现在与警告文字内联显示，不再悬浮在横幅中间

**🐛 修复**（38 条）

- 修复了 Bedrock 在剥离响应 Content-Type 头的代理后使用流式传输时的问题，该问题会导致每轮对话以非流式方式重新运行，使计费 API 调用悄然翻倍
- 修复了使用 Bedrock 且配置了 SSO profile 和 `awsAuthRefresh` 时，Claude Code 在 HTTPS 代理后启动卡住的问题——凭据预检查现在会遵循 `HTTPS_PROXY`
- 修复了从不存在的目录启动 Claude Code 时输出原始崩溃转储的问题；现在会打印清晰的提示信息
- 修复了 JetBrains IDE 终端中连接 Claude Code 插件时，Edit 和 Write 调用会暂停约 5 秒的问题
- 修复了一个竞态问题：在已有排队提示时按 Esc 可能让下一轮提前结束，导致 Claude 仍在工作时会话处于空闲，且后续重新提交会重复执行操作
- 修复了 WebFetch 在整个会话期间在内存中保留过期页面内容的问题，现在按预期的 15 分钟过期
- 修复了云端会话（Claude Code 网页版、桌面和移动应用）在空闲 worker 重启后脱离 plan 模式恢复的问题
- 修复了 MCP elicitation 表单在全屏模式下超过终端高度时被裁剪的问题：表单现在适配窗口，隐藏字段可通过滚动访问，Accept/Decline 按钮始终可见
- 修复了云端会话中或通过 SDK `setMcpServers()` 进行会话中重连时，远程 MCP 服务器因瞬时 5xx 错误而保持失败状态的问题
- 修复了重命名后写入超过约 64 KB 对话内容时，自定义会话标题从 `/resume` 中消失的问题
- 修复了 `claude -c`/resume 恢复路径仅以 `_`、`-` 或 `.` 等字符不同的其他目录会话的问题
- 修复了 `/resume` 和 agents 视图在会话文件仅被触碰或会话仅被重新打开时，将会话显示为最近变更（并重新排序）的问题
- 修复了 `/resume` 在全项目模式下要求你 `cd` 进入已删除目录（如已移除的 worktree）的问题；此类会话现在会在当前目录中恢复
- 修复了 `dark-ansi` 主题在全屏模式下渲染展开的工具结果时文字与背景颜色相同的问题
- 修复了全屏渲染器提示在永远无法回答的情况下每次启动都重复出现的问题；现在最多显示三次后停止
- 修复了 `.worktreeinclude` 以 `**/` 开头的模式在目标位于 gitignored 目录中时静默匹配不到任何内容的问题
- 修复了 `.md` 文件以 UTF-8 BOM 开头的 agents、skills 和 commands 被静默忽略的问题
- 修复了 `/insights` 在部分模型上响应中回显字面 `<message>` 标签的问题
- 修复了 marketplace 的 `metadata.pluginRoot` 不生效的问题：裸插件源名称现在会按照文档描述在其下解析
- 修复了浏览器终端中鼠标移动在鼠标报告跨写入分割时向提示插入类似 `"35;150;7M"` 文本的问题
- 修复了自定义主题对 effort/ultracode 状态徽章颜色的覆盖设置被忽略的问题
- 修复了 OpenTelemetry 追踪碎片化问题：被 `PreToolUse` hook 推迟的工具执行现在会在原始轮次的追踪中恢复，而不是开启新追踪
- 修复了 agent 视图中的 vim 模式：Escape 现在切换到 NORMAL 模式并保留你的文本，而不是清空提示
- 修复了 `selection:copy` 快捷键静默丢弃通过 Shift+方向键扩展的文本选区的问题
- 修复了通过 `voice.enabled` 设置启用语音听写后，`/voice` 启动提示仍然出现的问题
- 修复了 shell 模式（`!`）Tab 补全时从 `./script` 路径中丢弃 `./`，导致 shell 无法执行该命令的问题
- 修复了全屏模式下点击终端窗口仅为使其重新获得焦点时，误触发权限提示应答或按钮点击的问题
- 修复了全屏模式下斜杠命令面板（如 `/config`、`/model`）遮挡最新消息的问题；对话现在固定显示在面板上方
- 修复了在 Claude 仍在响应时打开 `/workflows` 详情对话框导致其溢出终端且标题栏超出屏幕的问题
- 修复了 Linux 沙箱因无法读取不存在的 `.git/config.worktree`，导致设置了 `extensions.worktreeConfig` 的仓库中所有沙箱 git 命令失败的问题
- 修复了会话工作目录被删除后 hooks 报错 "posix_spawn ENOENT" 的问题；现在会从项目根目录或主目录运行
- 修复了 `claudeMdExcludes` 在模式指定规则目录或符号链接而非其目标时，无法排除符号链接的 `.claude/rules` 文件的问题
- 修复了两个 Claude Code 进程共享同一后台任务状态时，会话标题向 Remote Control 疯狂同步的问题（2.1.232 回归）；标题更新现在会去重并限流
- 修复了标题以 `/` 开头的会话无法被 `SendMessage` 寻址，且在 `ListAgents` 中显示为 "(untitled)" 的问题
- 修复了光标位于 `[Pasted text #N]` 占位符内时，Ctrl+W、Ctrl+U、Ctrl+K、Option+Backspace、Option+D 和 vim `df`/`dt` 留下损坏占位符的问题
- 修复了登录码输入框等掩码（密码式）输入的文本可通过 Ctrl+Y 在别处粘贴，或被双击 Esc 清除后保存到提示历史的问题
- 修复了搜索框中 Ctrl+Backspace 只删除一个字符而非一个单词的问题
- 修复了被组织策略检查拒绝的请求在拒绝信息显示前被重新发送的问题
