# Claude Code v2.1.214 更新日志

> 🗓 2026-07-18 发布 · 📋 47 条更新（🚀 7 · 🔧 1 · 🔄 4 · 🐛 35）

**✨ 本版亮点**

- 🐛 **关键修复**：修复多个权限检查绕过漏洞，Bash/PowerShell 重定向、超长命令及 `dir/**` 规则匹配更严格
- 🚀 **新功能**：新增 EndConversation 工具，Claude 可结束滥用或越狱尝试的会话，与 claude.ai 行为一致
- 🚀 **新功能**：长时间运行的工具调用现会周期性输出进度心跳，不再静默无响应

**📋 更新明细**（共 47 条，按类别归组）

**🚀 新功能**（7 条）

- 新增 EndConversation 工具：Claude 可以结束高度滥用或越狱尝试用户的会话，与 claude.ai 自 2025 年以来的行为一致——详见 https://www.anthropic.com/research/end-subset-conversations
- 为长时间运行的工具调用新增周期性进度心跳，此前这些调用会静默无响应
- 为 memory 文件的 frontmatter 新增 ISO 格式的 `modified` 时间戳
- 为 OpenTelemetry 日志事件新增 `message.uuid`、`client_request_id` 和 `tool_source` 属性，用于消息级关联和工具溯源
- 新增 `CLAUDE_CODE_OTEL_CONTENT_MAX_LENGTH`，可配置 OpenTelemetry 内容属性 60 KB 的截断上限
- 在 `subagentStatusLine` 负载中加入 reasoning effort，自定义 agent 行现可同时展示模型和推理力度
- 为携带守护进程重定向标志（`--url`、`--connection`、`--identity` 及 Podman 远程模式）的 `docker` 命令（包括 Podman 的 `docker` shim）新增权限提示，此前此类命令无需确认即可运行

**🔧 改进**（1 条）

- 改进了在主目录下运行 `claude rc` 时的 workspace-trust 错误提示，明确说明此处信任永不会被保存，并建议在项目目录中运行

**🔄 变更**（4 条）

- 变更单段 `dir/**` hook `if:` 条件为仅匹配 `<cwd>/dir`；如需任意深度匹配请写 `**/dir/**`。`deny`/`ask` 权限规则保留任意深度匹配
- 变更使用 `-m`/`--magic-file` 或 `-f`/`--files-from` 的 `file` 命令为需要权限，不再作为只读命令自动放行
- 变更 keep-alive 连接池在出现过期连接错误后禁用，使重试会打开全新套接字
- 变更会话作为 fork 启动时 SessionStart hooks 报告来源为 "fork" 而非 "resume"

**🐛 修复**（35 条）

- 修复单段 `dir/**` 允许规则（如 `Edit(src/**)`）会自动批准写入目录树中任意位置的嵌套 `dir/` 目录、而非仅限 `<cwd>/dir` 的问题
- 修复影响 Windows PowerShell 5.1 会话中所运行命令的权限检查绕过漏洞
- 修复 Bash 权限检查问题：对于 bash 解析方式与权限分析器不同的文件描述符重定向形式，现在会以拒绝（fail closed）处理
- 修复 Bash 权限检查对超长命令的误判问题——超过 10000 字符的命令现在始终提示确认，不再自动运行
- 修复 Bash 权限检查将 `[[ ]]` 比较中的 zsh 变量下标和修饰符视为无害文本的问题——此类命令现在会提示确认
- 修复 Bash 权限检查问题：某些可能执行不安全选项、命令替换或反斜杠路径的 `help` 和 `man` 命令不再被自动批准
- 修复远程会话的权限提示可能先于本地确认对话框执行的问题
- 修复 feature flag 求值为 null 时的崩溃，以及格式错误的 flag 负载可能清空缓存 feature flags 的问题
- 修复 `pkill -f` 模式意外匹配到 CLI 自身进程时，Bash 工具会杀死 Claude 会话的问题（Linux）
- 修复 `--settings` 指向设备文件或多 GB 文件时的无限内存增长；超过 2 MiB 的设置文件现在会在启动时报错并给出清晰错误信息
- 修复 Windows 上企业代理后流式请求轮次报 "Socket is closed" 失败的问题
- 修复读取缓慢的 SDK/管道消费者在退出时 stream-json 输出被截断的问题；退出时的清空处理现在会随排队字节数动态调整，而非固定 2 秒上限
- 修复计划任务拒绝其自身配置的提示词（视为不可信输入）的问题——触发的提示词现在会作为会话的既定任务下发
- 修复 Windows 上子进程等待标准输入时 PowerShell 工具命令会一直挂起直到超时的问题
- 修复 Windows 上 PowerShell 工具下的 Python 脚本从标准输入读取非 UTF-8 数据时因 UnicodeDecodeError 崩溃的问题
- 修复 Windows 上通过 PowerShell 工具运行的 Python 脚本在输出非 ASCII 内容时因 UnicodeEncodeError 崩溃的问题，以及 PowerShell 7 错误信息中包含原始 ANSI 转义序列的问题
- 修复 PowerShell 工具将返回有效否定结果的 `where.exe`、`fc.exe` 和 `diff.exe` 误报为错误的问题（Windows）
- 修复 Windows PowerShell 5.1 下 PowerShell 工具中 `>` 和 `>>` 写出其他工具无法按 UTF-8 读取的 UTF-16LE 文件的问题
- 修复一个错位的后台守护进程在关闭时删除其继任者的控制套接字、导致下一个客户端杀死健康替代守护进程的问题
- 修复用 `←` 或 `/background` 挂起并闲置的后台会话会让后台守护进程和一个 worker 进程无限存活的问题
- 修复后台服务进入空闲后，已完成的后台会话无法通过 `claude rm` 或 agent 视图移除的问题
- 修复从非 git 目录分发的后台会话无法从 agents 视图删除的问题
- 修复会话存储中存在不可读文件夹时，重新打开已停止的后台会话无法恢复其保存的对话的问题
- 修复未显式启用 Remote Control 的会话也会触发 Remote Control "session ready" 推送通知的问题
- 修复 `/install-github-app` 和 `/mcp` 设置菜单在 agent 视图会话中被阻止的问题——现在仅在无终端连接的后台会话中被拒绝
- 修复通过 `--settings` CLI 标志启用的插件未加载的问题（v2.1.181 以来的回归）
- 修复 OAuth 令牌轮换后长时会话中 feature flags 过期失效的问题
- 修复 `/ultrareview` 在无 merge base 的仓库中拒绝运行的问题——现在会提供审查所有已跟踪文件的选项
- 修复 shell 配置路径为目录时 `claude update` 和 `claude doctor` 静默挂起、以及 `/status` 的 System diagnostics 部分显示为空白的问题
- 修复保存 memory 文件时 frontmatter 值在行内 `#` 处被静默截断的问题
- 修复发出多个累计 `message_delta` 帧的流中会话成本和 token 遥测重复计数的问题
- 修复 advisor 思考期间出现的虚假 "check your network" 警告
- 修复 hook 的 stdout JSON 未通过 schema 校验时，退出码为 2 的 hook 未按文档说明进行阻止的问题
- 修复在轮次的异步上下文之外发出的 OTel 日志事件缺失 interaction span 的 trace 上下文的问题
- 修复提示词/资源刷新期间的 MCP 瞬时错误会清空服务器斜杠命令和资源的问题
