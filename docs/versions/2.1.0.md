# Claude Code v2.1.0 更新日志

> 🗓 2026-01-07 发布 · 📋 109 条更新（🚀 28 · 🔧 21 · 🔄 5 · 🐛 54 · 📌 1）

**✨ 本版亮点**

- 🚀 **新功能**：技能支持热重载，`~/.claude/skills` 下的改动即时生效，无需重启会话
- 🚀 **新功能**：Bash 权限规则支持 `*` 通配符，可灵活匹配任意位置的命令模式
- 🔧 **改进**：Shift+Enter 在 iTerm2、WezTerm、Ghostty、Kitty 中开箱即用，Ctrl+B 可统一后台化任务
- 🔧 **改进**：输出因 token 上限被截断时自动继续，不再报错中断
- 🐛 **关键修复**：修复敏感数据（OAuth 令牌、API 密钥、密码）可能在调试日志中泄露的安全问题

**📋 更新明细**（共 109 条，按类别归组）

**🚀 新功能**（28 条）

- 新增技能（skill）自动热重载——在 `~/.claude/skills` 或 `.claude/skills` 中创建或修改的技能无需重启会话即可立即生效
- 新增在技能 frontmatter 中使用 `context: fork`，以 fork 子代理（sub-agent）上下文运行技能和斜杠命令
- 新增技能中的 `agent` 字段，用于指定执行时的代理类型
- 新增 `language` 设置项，可配置 Claude 的回复语言（例如 language: "japanese"）
- 新增 `settings.json` 中的 `respectGitignore` 设置，可按项目控制 @-mention 文件选择器行为
- 新增 `IS_DEMO` 环境变量，可在 UI 中隐藏邮箱和组织信息，适用于直播或录屏场景
- 新增 Bash 工具权限的通配符匹配：规则中任意位置均可使用 `*`（例如 `Bash(npm *)`、`Bash(* install)`、`Bash(git * main)`）
- 新增统一的 Ctrl+B 后台化操作——同时适用于 bash 命令和代理，按下 Ctrl+B 可将所有前台运行的任务一并转入后台
- 新增对 MCP `list_changed` 通知的支持，MCP 服务器可动态更新其工具、提示和资源，无需重新连接
- 新增 `/teleport` 和 `/remote-env` 斜杠命令（面向 claude.ai 订阅用户），可用于恢复和配置远程会话
- 新增在 settings.json 权限中使用 `Task(AgentName)` 语法或 `--disallowedTools` CLI 参数来禁用特定代理
- 新增代理 frontmatter 中的 hooks 支持，代理可定义限定于其生命周期的 PreToolUse、PostToolUse 和 Stop hooks
- 新增技能和斜杠命令 frontmatter 中的 hooks 支持
- 新增 Vim 动作：`;` 和 `,` 重复 f/F/t/T 动作，`y` 操作符配合 `yy`/`Y` 复制，`p`/`P` 粘贴，文本对象（`iw`、`aw`、`iW`、`aW`、`i"`、`a"`、`i'`、`a'`、`i(`、`a(`、`i[`、`a[`、`i{`、`a{`），`>>` 和 `<<` 缩进/取消缩进，以及 `J` 合并行
- 新增 `/plan` 命令快捷方式，可直接在提示词中启用计划模式（plan mode）
- 新增斜杠命令自动补全：`/` 出现在输入任意位置时均可触发，不再限于开头
- 新增交互模式下的 `--tools` 参数，可限制 Claude 在交互会话中可使用的内置工具
- 新增 `CLAUDE_CODE_FILE_READ_MAX_OUTPUT_TOKENS` 环境变量，可覆盖默认的文件读取 token 上限
- 新增 hooks 的 `once: true` 配置支持
- 新增 frontmatter `allowed-tools` 字段的 YAML 风格列表支持，技能声明更简洁
- 新增对来自插件的 prompt 和 agent hook 类型的支持（此前仅支持 command hooks）
- 新增 iTerm2 中 Cmd+V 粘贴图片的支持（映射为 Ctrl+V）
- 新增在对话框中使用左右方向键切换标签页
- 新增 Ctrl+O 转录（transcript）模式下的实时思考块（thinking block）显示
- 在后台 bash 任务详情对话框的完整输出中新增文件路径显示
- 在上下文可视化中将 Skills 作为独立类别显示
- [VSCode] 在上下文菜单中显示当前选中的模型名称
- [VSCode] 为自动接受权限按钮添加了描述性标签（例如用 "Yes, allow npm for this project" 代替 "Yes, and don't ask again"）

- 改进 subagent（Task 工具）在权限被拒绝后继续工作，允许其尝试替代方案
