**📋 更新明细**（共 50 条，按类别归组）

**🚀 新功能**（7 条）

- 新增 agent 视图（Research Preview）：以单一列表展示所有 Claude Code 会话——运行中、等待你操作或已完成。运行 `claude agents` 开始使用。详见 https://code.claude.com/docs/en/agent-view
- 新增 `/goal` 命令：设定完成条件后，Claude 会跨多轮持续工作直至达成。支持交互模式、`-p` 和 Remote Control，并以悬浮面板实时显示已用时间/轮次/token 数
- 新增 `/scroll-speed` 命令，可调节鼠标滚轮滚动速度并实时预览
- 新增 `claude plugin details <name>`，可展示插件的组件清单及每会话预估 token 成本
- 新增会话记录视图导航：`?` 查看键盘快捷键，`{`/`}` 在用户提示之间跳转，`v` 切换快捷键面板
- hook 新增 `args: string[]` 字段（exec 形式），直接启动命令而不经过 shell，路径占位符无需再加引号
- hook 为 `PostToolUse` 新增 `continueOnBlock` 配置项——设为 `true` 时，hook 的拒绝原因会回传给 Claude 并继续本轮执行

**🔧 改进**（10 条）

- MCP stdio 服务器的环境变量中现在会包含 `CLAUDE_PROJECT_DIR`，与 hooks 保持一致。插件配置可在命令中引用 `${CLAUDE_PROJECT_DIR}`
- 压缩（Compaction）提示词现在会要求模型保留敏感的用户指令
- `/mcp` Reconnect 现在无需重启即可读取 `.mcp.json` 的修改，重连失败时会显示 HTTP 状态码和 URL
- `/context all` 中各 skill 的 token 估算现在基于模型自身的分词器计算，并显示取整后的数值
- `claude plugin install <name>@<marketplace>` 现在会先自动刷新 marketplace 并重试，再报告插件未找到
- `/plugin` 中已安装插件的详情现在能清晰地显示 hook 事件名和 MCP 服务器名
- `/context` 现在会为来自插件的 skill 显示其所属插件名称
- 所有用户现在均可使用远程 MCP 服务器在瞬时故障时的自动重连重试
- 子代理发出的 API 请求现在携带 `x-claude-code-agent-id` / `x-claude-code-parent-agent-id` 请求头，`claude_code.llm_request` OTEL span 也包含 `agent_id` / `parent_agent_id` 属性
- 当设置了 `ANTHROPIC_API_KEY` / `apiKeyHelper` / `ANTHROPIC_AUTH_TOKEN` 时，即使同时存在 Claude.ai 登录，Remote Control、`/schedule`、claude.ai MCP 连接器和通知偏好也会被禁用。如需使用这些功能，请取消设置 API key

**🐛 修复**（32 条）

- 修复了凭据过期与 `forceRemoteSettingsRefresh` 策略设置叠加导致 `claude auth login`/`logout`/`status` 死锁且无法恢复的问题
- 修复了 `autoAllowBashIfSandboxed` 不会自动批准含 `$VAR` 和 `$(cmd)` 等 shell 展开命令的问题
- 修复了 hook 向终端写入内容可能损坏屏幕上交互式提示的问题；hooks 现在在没有终端访问权的环境下运行
- 修复了 HTTP/SSE MCP 服务器流式传输非协议数据时内存无限增长的问题——响应体现在限制为每个 SSE 帧最多 16 MB
- 修复了 `Skill(name *)` 权限规则——通配符形式现在可作为前缀匹配使用，与 `Bash(ls *)` 行为一致
- 修复了设置热重载无法检测到通过符号链接的 `~/.claude/settings.json` 被编辑的问题
- 修复了 marketplace 键名与清单名称不一致时插件详情加载失败的问题
- 修复了 `/model` 选择器的 "Default" 行未反映 `ANTHROPIC_DEFAULT_OPUS_MODEL`/`ANTHROPIC_DEFAULT_SONNET_MODEL` 覆盖配置的问题
- 修复了响应完成 5 分钟后出现虚假 "stream idle timeout" 的问题，原因是流取消时未清除看门狗计时器
- 修复了配置 10 个以上 MCP 服务器且缓存目录不可写时静默 `exit 1` 的问题——错误信息现在会包含底层原因
- 修复了对话框中标签名、列表指针和选中行上出现打字光标闪烁的问题
- 修复了会话记录视图中鼠标点击后字母快捷键失效的问题
- 修复了 Bash 模式下按上箭头调出历史时重复第一条记录并覆盖正在编辑草稿的问题
- 修复了一次粘贴或拖入多张图片时只插入最后一张的问题
- 修复了超链接在深色主题下使用难以辨认的深蓝色的问题——现在会自适应当前主题
- 修复了模型选择器对模型设为 `opus` 别名的第三方用户显示多余的 "Current model" 行的问题
- 修复了 PAYG 第三方提供商上旧版 Opus 选择项解析到与默认项相同模型的问题
- 修复了 Cursor 和 VS Code 1.92–1.104 中鼠标滚轮滚动速度的问题；触控板现在以稳定速率滚动，鼠标滚轮每格约滚动 3 行
- 修复了附加到后台会话时 Windows Terminal 和 VS Code 中的滚动行为
- 修复了已断开连接服务器的 MCP 资源残留在 `@server:` 自动补全中的问题
- 修复了双文件 diff 片段截断行数多报一行的问题
- 修复了 Grep 结果不对 Windows 盘符路径做相对化处理，以及单文件路径下计数模式统计总数错误的问题
