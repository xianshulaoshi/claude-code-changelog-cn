# Claude Code v2.1.128 更新日志

> 🗓 2026-05-04 发布 · 📋 37 条更新（🔧 10 · 🐛 25 · 📌 2）

**✨ 本版亮点**

- 🐛 **关键修复**：修复并行 Bash 调用中只读命令失败导致兄弟调用被取消的问题
- 🐛 **关键修复**：修复 1M 上下文模型因压缩窗口较小被误报“Prompt is too long”
- 🔧 **改进**：MCP 重连不再刷屏工具列表，改为按服务器前缀汇总展示
- 🚀 **新功能**：--plugin-dir 支持 .zip 插件包，/mcp 可查看服务器工具数
- 🐛 **关键修复**：修复管道传入超大输入（>10 MB）到 claude -p 时导致的崩溃循环

**📋 更新明细**（共 37 条，按类别归组）

**🔧 改进**（10 条）

- 裸 `/color`（无参数）现在会随机选择一个会话颜色
- `/mcp` 现在会显示已连接服务器的工具数量，并标记连接后工具数为 0 的服务器
- `--plugin-dir` 除目录外，现在还支持 `.zip` 插件压缩包
- `--channels` 现可在 console（API key）认证下使用——启用了托管设置的 console 组织需设置 `channelsEnabled: true` 才能启用
- 更新 `/model` 选择器：合并了重复的 Opus 4.7 条目，当前 Opus 现在显示为 "Opus" 而非 "Opus 4.7"
- MCP：`workspace` 现为保留服务器名——已存在的同名服务器将被跳过并给出警告
- SDK 宿主现在会在 Bash 权限提示时收到持久化的 `localSettings` 建议，"Always allow" 会写入 `.claude/settings.local.json`
- `EnterWorktree` 现按文档所述从本地 HEAD 创建新分支，而不是 `origin/<default-branch>`——未推送的提交不再丢失
- Auto 模式：当分类器无法评估某项操作时，错误信息现在包含提示（重试、`/compact` 或使用 `--debug` 运行）
- Headless `--output-format stream-json`：`init.plugin_errors` 现在除依赖降级外，还包含 `--plugin-dir` 加载失败

**🐛 修复**（25 条）

- 修复提交新提示时 focus mode 短暂调暗上一条回复的问题
- 修复在 Kitty 及其他将 OSC 9 解释为通知的终端中每次 `/exit` 都出现多余的 "4;0;" 桌面通知的问题
- 修复 Remote Control 在限流时显示空白的 "Opening your options…" 消息而非可操作的升级选项
- 修复拖拽上传图片在图片读取失败时卡在 "Pasting text…" 的问题
- 修复通过 stdin 向 `claude -p` 管道传入超大输入（>10 MB）时的崩溃循环
- 修复全屏模式下长 URL 在每个折行处无法单独点击的问题
- 修复通过 `--plugin-dir` 加载的插件在 `/plugin` Components 面板中显示 "Marketplace 'inline' not found" 的问题
- 修复 MCP 工具结果在服务器同时返回结构化内容和 content blocks 时丢失图片的问题
- 修复复制粘贴时列表项内代码块的前导空白被带入剪贴板的问题
- 修复 `/config` 中的 Tab 导航导致焦点滞留——标签页头部现在保持焦点，方向键和 Esc 可继续使用
- 修复在不支持 OSC 8 超链接的终端上 markdown 链接标签丢失的问题——链接现在渲染为 `label (url)` 而非仅显示 URL
- 修复 1M 上下文模型在压缩窗口较小时未达到实际 API 限制就被误报 "Prompt is too long" 而阻断的问题
- 修复并行 shell 工具调用：只读命令（grep、git diff、ls）失败不再取消兄弟调用
- 修复在不支持 effort 的模型上 banner 显示 "with X effort" 的问题
- 修复第三方提供商上 `/fast` 模糊匹配到无关 skill 而非显示 "not available" 的问题
- 修复 Bedrock 默认模型解析为 `global.*` 而非区域对应前缀的问题
- 修复 vim 模式：NORMAL 模式下 `Space` 现在将光标右移，与标准 vi/vim 行为一致
- 修复终端进度指示器（OSC 9;4）在工具调用之间闪烁消失的问题——现在在整个回合中保持可见
- 修复无参数的 `/rename` 在最后一条记录为 compact 边界的恢复会话上失败的问题
- 修复 `--resume`/`--continue` 后出现先前会话残留的 "remote-control is active" 状态行的问题
- 修复指向已删除缓存目录的过期 `installed_plugins.json` 条目污染 PATH 的问题
- 修复设置了 `CLAUDE_CODE_SHELL_PREFIX` 且参数包含空格或 shell 元字符时 MCP stdio 服务器收到损坏参数的问题
- 修复子代理进度摘要缺失提示缓存的问题（`cache_creation` 减少约 3 倍）
- 修复 `/plugin update` 从未检测到 npm 来源插件新版本的问题
- 修复子代理转录静止时其摘要反复触发的问题，限制了空闲子代理的最坏 token 开销

**📌 其他**（2 条）

- 子进程（Bash、hooks、MCP、LSP）不再继承 `OTEL_*` 环境变量，通过 Bash 工具运行的 OTEL 插桩应用不会再拾取 CLI 自身的 OTLP 端点
- MCP 服务器重连时不再在每次重连时用完整工具名列表刷屏——重新声明的工具会按服务器前缀汇总展示
