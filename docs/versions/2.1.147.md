# Claude Code v2.1.147 更新日志

> 🗓 2026-05-21 发布 · 📋 33 条更新（🔧 3 · 🔄 1 · 🐛 28 · 📌 1）

**✨ 本版亮点**

- 🚀 **新功能**：/simplify 更名为 /code-review，可按指定深度检查正确性 bug，并支持将结果发布为 GitHub PR 行内评论
- 🔧 **改进**：置顶的后台会话空闲时保持存活，更新时原地重启，且仅在内存压力下最后被释放
- 🔧 **改进**：大文件编辑的 diff 渲染性能显著提升，自动更新器更健壮并支持失败重试
- 🐛 **关键修复**：修复企业登录限制可被第三方登录与 API key 会话绕过的问题
- 🐛 **关键修复**：修复粘贴文本被以不可读的 [Pasted text #N] 占位符发送给模型

**📋 更新明细**（共 33 条，按类别归组）

**🔧 改进**（3 条）

- 置顶的后台会话（在 `claude agents` 中按 `Ctrl+T`）空闲时保持存活，应用 Claude Code 更新时会原地重启，且仅在内存压力下、非置顶会话之后才被释放
- 改进自动更新器：对临时性网络失败进行重试，失败时报告具体错误类别和操作系统错误码，并显示当前版本号
- 提升大文件编辑时的 diff 渲染性能

**🔄 变更**（1 条）

- 将 `/simplify` 更名为 `/code-review`，现可按指定深度级别报告正确性 bug（如 `/code-review high`）；传入 `--comment` 可将发现的问题以行内评论形式发布到 GitHub PR。旧的清理与修复行为已移除

**🐛 修复**（28 条）

- 修复企业登录限制（`forceLoginOrgUUID` 与 `forceLoginMethod` 托管设置）未对第三方提供商和 API key 会话强制生效的问题
- 修复 `!` 命令输出中 `&` 显示为 `&amp;` 的问题，该问题曾导致在无头机器上无法从 `gcloud auth login` 等命令复制粘贴 URL
- 修复未知斜杠命令在 headless/SDK 模式下静默无反应的问题——现在会显示错误信息
- 修复 `/help` 渲染出损坏的标签页标题，以及非全屏模式下在小终端中每页只显示一条命令的问题
- 修复 shell 快照丢失名称以单个下划线开头的用户函数，导致引用这些函数的别名失效
- 修复插件 agent 在 `tools:` frontmatter 中声明多个 `Agent(...)` 类型时只保留最后一项的问题
- 修复 hook 的 `if` 条件如 `PowerShell(git push*)` 永远无法匹配的问题——此前只有 `PowerShell(*)` 生效
- 修复 PowerShell 工具丢失依赖默认格式化器的命令输出
- 修复：在 Windows 上，为 PowerShell 脚本调用选择"Yes, and don't ask again"后，现在会写入一条在后续运行中真正能匹配的规则
- 修复 Windows 上 `pwsh` 通过 winget 或 Microsoft Store 安装时 PowerShell 工具以退出码 1 失败的问题
- 修复 `/effort` 打开时滑块停在不正确的档位——现在会从当前 effort 级别开始
- 修复 MCP 服务器分页时丢失第 1 页之后的资源、模板和提示
- 修复 Windows Terminal 中附加的后台会话在 Claude 流式输出时出现全屏闪烁的问题
- 修复：在 Windows 上，移除后台任务工作树不再沿 NTFS junction 进入主仓库
- 修复 `/background` 拒绝那些仅输入过 skill 或自定义斜杠命令的会话
- 修复 auto 模式在用户或 skill 明确依赖 `AskUserQuestion` 时将其抑制的问题；auto 模式分类器现在会将用户的回答视为意图信号
- 修复 `/theme` 的"新建自定义主题"和颜色编辑对话框不响应 Esc 的问题
- 修复通过 Agent SDK 运行时流式会话结束时出现未捕获异常
- 修复 Windows 上等待滚动停止时偶发的挂起
- 修复 Windows 上后台会话结果包含宽字符（CJK）时 agent 视图列表出现残留和重复行的问题
- 修复粘贴文本以不可读的 `[Pasted text #N]` 占位符而非实际内容发送给 agent 的问题
- 修复插件 manifest 中列出的路径与其默认目录重叠时，`claude plugin details` 和 `/plugin` 中插件组件数量翻倍的问题
- 修复后台会话重新请求你已通过"don't ask again"授予的工具权限
- 修复 GNOME Terminal 中右键和中键粘贴无法插入文本的问题
- 修复 `CLAUDE_CODE_SUBAGENT_MODEL` 未应用于 agent 团队生成的 teammate 进程
- 修复斜杠命令后跟制表符或换行符时被当作未知命令处理的问题
- 修复 `/plugin`、`/status`、`/mobile`、`/sandbox` 和 `/permissions` 菜单中的多处间距与布局问题
- 修复被剥离的图像导致模型反复重新读取已不存在的媒体文件的问题
