**✨ 本版亮点**

- 🐛 **关键修复**：修复 token 无限刷新循环，解决 Slack 等 OAuth MCP 服务器连接卡死问题
- 🐛 **关键修复**：修复读写大文件（尤其是 base64 图片）时的内存崩溃

- 🔧 **改进**：基于 Rust 原生模糊查找器，文件路径建议性能显著提升
