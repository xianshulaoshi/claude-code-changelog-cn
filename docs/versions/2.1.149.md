# Claude Code v2.1.149 更新日志

> 🗓 2026-05-22 发布 · 📋 26 条更新（🚀 1 · 🔧 4 · 🐛 21）

**✨ 本版亮点**

- 🚀 **新功能**：`/usage` 新增分类明细：按 skills、subagents、插件及各 MCP 服务器查看用量与成本
- 🔧 **改进**：Markdown 输出支持渲染 GFM 任务清单复选框，`/feedback` 附带压缩前对话便于排查
- 🐛 **关键修复**：修复 PowerShell `cd..` 等内置命令绕过权限检查的安全漏洞
- 🐛 **关键修复**：修复 `find` 在大目录树上耗尽 macOS 系统文件表导致主机崩溃的问题
- 🐛 **关键修复**：修复 Ctrl+O 会话记录视图冻结、不再追踪新消息的问题

**📋 更新明细**（共 26 条，按类别归组）

**🚀 新功能**（1 条）

- 企业版：新增 `allowAllClaudeAiMcps` 托管设置，可与 `managed-mcp.json` 一同加载 claude.ai 云端 MCP 连接器

**🔧 改进**（4 条）

- `/usage` 现在可按类别展示限制用量的来源明细——skills、subagents、插件，以及各 MCP 服务器的成本
- `/diff` 详情视图现在支持键盘滚动（方向键、`j`/`k`、`PgUp`/`PgDn`、`Space`、`Home`/`End`）
- Markdown 输出现在会渲染 GFM 任务清单复选框（`- [ ] todo` / `- [x] done`），而不是普通项目符号
- 改进 `/feedback` 报告，现在会包含上下文压缩之前的对话，使长会话中早期出现的问题更易于排查

**🐛 修复**（21 条）

- 修复 PowerShell 权限绕过问题：内置 `cd` 函数（`cd..`、`cd\`、`cd~`、`X:`）可在未被检测的情况下切换工作目录，使后续命令能读取工作区之外的文件
- 修复 git worktree 中沙箱写入白名单覆盖整个主仓库根目录的问题，现在仅覆盖共享的 `.git` 目录（并拒绝 `hooks/` 和 `config`）
- 修复 PowerShell 前缀/通配符允许规则（如 `PowerShell(dotnet.exe build *)`）无法预批准原生可执行文件和脚本的问题
- 修复权限分析缺口：解析器在 `cd`/`pushd`/`popd` 之后仍信任过期的 `PWD`/`OLDPWD`/`DIRSTACK` 变量追踪值
- 修复 Bash 工具中的 `find` 在大型目录树上耗尽 macOS 系统文件/vnode 表并导致主机崩溃的问题
- 修复托管设置审批对话框在启动时被接受后终端保持冻结的问题
- 修复工作树无实际改动时，`/ultraplan` 和远程会话创建因 "Could not capture uncommitted changes" 而失败的问题
- 修复 `otelHeadersHelper` 在脚本路径包含空格时静默失败的问题；helper 失败现在会在 `/doctor` 和调试日志中上报
- 修复思考加载动画（spinner）在工具调用期间及新一轮思考开始时始终保持琥珀色的问题
- 修复折叠的 Bash 输出对包含大量短行的输出报告错误隐藏行数的问题
- 修复斜杠命令参数提示溢出输入框时会截断已输入尾部字符的问题
- 修复通过 Tab 补全 skill 后，若其 frontmatter `name:` 与目录名不一致，参数提示和渐进式参数建议不再显示的问题
- 修复状态栏显示用户基线 `/effort` 设置，而非 skill/agent `effort:` frontmatter 所生效的努力级别的问题
- 修复 Ctrl+O 会话记录视图在打开时刻冻结、不再追踪新消息的问题
- 修复编辑调出的历史提示记录后，继续用方向键上下导航时丢失编辑内容的问题
- 修复 `/config` 退出摘要在切换无关设置时误报 auto-compact 和主题出现幻影变更的问题
- 修复缓存的会话元数据文件缺少可选字段时 `/insights` 崩溃的问题
- 修复输入缺失的格式错误的 PowerShell 和 History 工具调用在会话记录折叠中被误分类为读取操作的问题
- 修复从 claude.ai 或 Claude 移动应用重命名 Remote Control 会话后，本地会话名称未同步更新至 `claude --resume` 的问题
- 修复刚提交的提示可能在上箭头历史中重复出现两次的竞态问题
- 修复全屏模式下点击 "Jump to bottom" 悬浮按钮未立即消失的问题
