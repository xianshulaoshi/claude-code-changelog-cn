# Claude Code v2.1.203 更新日志

> 🗓 2026-07-07 发布 · 📋 37 条更新（🚀 4 · 🔧 3 · 🔄 4 · 🐛 26）

**✨ 本版亮点**

- 🐛 **关键修复**：修复 macOS 后台会话打开或切换时卡顿 15–20 秒的问题（2.1.196 引入的回归）
- 🐛 **关键修复**：修复后台会话因 daemon 令牌过期而永久无响应，现已可自动恢复
- 🔧 **改进**：长响应流式输出时界面更流畅，实时预览不再整屏重绘
- 🚀 **新功能**：登录即将过期时新增提醒，可提前重新认证避免后台会话中断
- 🔧 **改进**：二进制体积与启动内存各减少约 7 MB，子代理更少把任务整体转交他人

**📋 更新明细**（共 37 条，按类别归组）

**🚀 新功能**（4 条）

- 新增登录即将过期的提醒，可在后台会话被中断前提前重新认证
- 处于手动权限模式时，底部栏会显示灰色 ⏸ 徽标，让当前模式始终可见
- 将会话的额外工作目录加入 MCP `roots/list`，并在集合变化时发送 `notifications/roots/list_changed`
- [VSCode] 新增设置开关"为所有会话启用 Remote Control"

**🔧 改进**（3 条）

- 改进长响应流式输出期间的响应速度：实时预览更新不再重绘整个屏幕
- 改进子代理行为：代理现在更少把整个任务重新转交给另一个子代理
- 通过延迟加载而非内联一个大型捆绑依赖，二进制体积减少约 7 MB，启动内存减少约 7 MB

**🔄 变更**（4 条）

- 更改左方向键不再关闭后台任务、diff 与工作流详情视图——请改按 Esc
- 更改 `claude agents` 空视图始终显示分好类的区块（Needs input / Working / Completed）及其说明
- 移除启动时的 "claude command missing or broken" 警告——这些信息现在改在 `/doctor` 和 `/status` 中显示
- 移除 `claude agents` 底部栏中冗余的导航提示

**🐛 修复**（26 条）

- 修复 macOS 上打开或切换后台代理会话时因错误的低内存检测而卡顿 15–20 秒的问题（2.1.196 引入的回归）
- 修复后台会话在 daemon 的会话令牌过期后对 attach、回复和停止永久无响应的问题——会话现在可自动恢复
- 修复返回 `claude agents` 时会静默停止正在运行的子代理并从头重新执行提示的问题——它们的工作现在会保留
- 修复交互式会话中的内存与每轮 CPU 回归：上下文用量指示器不再在每一轮后重新分析整个对话记录
- 修复后台代理从 daemon 继承过期的 `PATH` 而非派发 shell 的 PATH，导致 Windows 上找不到工具的问题
- 修复后台与代理视图会话丢失 shell 导出的 `ANTHROPIC_BASE_URL`，导致 API 密钥被发送到默认端点并返回 401 的问题
- 修复在包含大量 git worktree 的仓库中 Bash 报错 "argument list too long" 的问题
- 修复 worktree 隔离的子代理有时在父检出目录而非自己的 worktree 中执行 shell 命令的问题
- 修复 worktree 创建时拒绝多仓库工作区中的嵌套仓库，导致后台会话无法隔离并编辑的问题
- 修复后台代理在工作目录被删除、被文件替换或变为无效路径时陷入崩溃循环的问题——现在会清晰报错并一次性失败
- 修复后台 daemon 自动升级失败时会静默杀掉所有正在运行的后台会话的问题
- 修复 `TaskStop` 和 `TaskOutput` 无法找到由其他代理派生的后台代理的问题——错误信息现在会按 id 和描述列出正在运行的代理
- 修复在 `claude agents` 输入框中输入斜杠命令但该处不可用时，已输入消息被丢弃的问题
- 修复打开一个对话已在其他会话中打开的已停止会话时代理列表崩溃的问题
- 修复问题已被回答后，后台会话在代理列表中仍显示 "Needs input" 的问题
- 修复后台代理启动失败时只显示 "exit_with_message" 而非实际错误的问题
- 修复通过 daemon 派生的后台会话忽略 settings.json 中 `effortLevel` 更改的问题
- 修复 attach 的后台会话忽略 `CLAUDE_CODE_DISABLE_MOUSE` 和 `CLAUDE_CODE_DISABLE_MOUSE_CLICKS` 退出选项的问题
- 修复所有已命名代理完成后 `/exit` 仍错误警告有后台代理在运行的问题
- 修复配置了 `WorktreeCreate` hook 时，从非 git 目录启动的后台会话无法编辑文件的问题
- 修复 `claude agents` 中 `@` 目录选择器不显示已注册 git worktree 的问题
- 修复 Windows 上 `/clear` 后后台任务输出被空文件永久覆盖的问题
- 修复向上滚动较长对话历史时内容跳动的问题
- 修复 bash 模式下显示 shell 历史建议时输入过程中终端闪烁跳动的问题
- 修复重新 attach 到后台会话时打印出字面 `^[[I` / `^[[O` 转义码的问题
- 修复仅含 LSP 的插件在其语言服务器提供诊断或响应导航请求时被错误标记为未使用的问题
