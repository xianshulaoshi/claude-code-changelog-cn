# Claude Code v2.1.208 更新日志

> 🗓 2026-07-13 发布 · 📋 46 条更新（🚀 4 · 🔧 11 · 🔄 1 · 🐛 28 · 📌 2）

**✨ 本版亮点**

- 🚀 **新功能**：新增屏幕阅读器模式，支持纯文本渲染，可通过启动参数或设置开启
- 🚀 **新功能**：vim 模式支持 `vimInsertModeRemaps`，可将 `jj` 等键序映射为 Escape
- 🔧 **改进**：大幅优化性能与内存：会话记录最多缩小 79 倍，修复多个长会话内存泄漏
- 🔧 **改进**：即使开启 `--dangerously-skip-permissions`，灾难性命令（如 `rm -rf ~`）也会弹出确认
- 🐛 **关键修复**：修复 CLI 自动更新后上下文窗口被重置为 200k、恢复长上下文会话误报已满的问题

**📋 更新明细**（共 46 条，按类别归组）

**🚀 新功能**（4 条）

- 新增屏幕阅读器模式：为屏幕阅读器用户提供可选的纯文本渲染。可运行 `claude --ax-screen-reader`、设置 CLAUDE_AX_SCREEN_READER=1，或在设置中添加 "axScreenReader": true。
- 新增 `vimInsertModeRemaps` 设置：在 vim 模式下可将 `jj` 等双键插入模式键序映射为 Escape
- 新增 `CLAUDE_CODE_PROCESS_WRAPPER`：agent 视图和后台服务现在会将 Claude Code 的每次自派生进程交由企业启动器要求的包装可执行文件来运行
- 全屏模式下，多选菜单和 "Other" 输入行新增鼠标点击支持

**🔧 改进**（11 条）

- 改进 agent 任务列表更新时的输入响应速度——任务更新不再重新渲染整个 UI
- 通过缓存工具池组装，降低含大量 MCP 工具的 print/SDK 会话中每次工具调用的 CPU 开销（工具数量多时工具轮次最快提升 7 倍）
- 将文件编辑读取缓存限制为 16 MB 而非固定最多 1,000 个完整文件，以降低内存占用
- 通过清理被取代的文件历史备份，缩减会话记录体积（编辑密集型会话最多缩小 79 倍），并限制检查点的磁盘用量
- 降低恢复含后台 agent 或从大型对话派生的 fork 会话时的内存占用
- 已完成的后续 agent 现在会保留在 `/tasks` 列表中直到清理，而不再是完成即消失
- attach 到已停止的后台 agent 时，现在会在会话预热期间立即显示其记录，而非空白的 "Session is starting" 界面
- agent 视图：Ctrl+X 现在会删除已重命名分支的 worktree、绝不销毁未推送的提交、保留 worktree 时保留对应会话行，且复用的 worktree 名称会重置为当前基准
- 包含 `$(…)`/反引号/`<(…)` 的命令中的灾难性删除操作（如 `rm -rf ~`），现在在 `--dangerously-skip-permissions` 和自动模式下也会弹出提示，与普通写法保持一致
- 配置了空 URL 的 MCP 服务器现在在 `/mcp` 中显示为 "not configured"，而非配置错误
- 当用量接口被限流时，`/usage` 现在会显示最近一次的用量柱状图并附 "as of" 标注，而非报错界面

**🔄 变更**（1 条）

- 调整 Fable 5 用量积分同意提示，使其默认聚焦在拒绝选项上

**🐛 修复**（28 条）

- 修复切回支持快速模式的模型后快速模式保持关闭的问题——现在若设置中已启用，会自动恢复
- 修复发给后台 agent 的回复在投递失败时丢失的问题——文本现在会被保存，并在会话重启后完成投递
- 修复更新替换了正在运行的 `claude agents` 进程所依赖的二进制后，后台会话 attach 永久失败（"Couldn't start the background daemon"）的问题
- 修复 CLI 自动更新后上下文窗口（及自动压缩指示器）被短暂重置为 200k 的问题，该问题会导致恢复长上下文会话时误报 "100% context used"
- 修复服务器在请求进行中通过 GOAWAY 关闭 HTTP/2 连接时，受监督会话和后台会话崩溃的问题
- 修复 `claude -p` 管道输出大响应时 stream-json/JSON 输出被截断、缺少结果消息的问题
- 修复 `CLAUDE_CODE_MAX_OUTPUT_TOKENS` 等环境变量在使用科学计数法值时被静默取用尾数的问题（`1e6` 变成了 `1`）
- 修复超大 markdown 表格导致渲染卡顿或内存占用过高的问题；超过 200 行的表格只显示前 200 行并附 "… N more rows" 提示
- 修复 Edit 工具在文件读取后被修改、但目标文本仍可唯一匹配时失败的问题
- 修复 Read 将空文件报告为 "shorter than offset"、Grep 对无效正则静默返回 "No files found"、Grep 计数模式在分页时少计总数，以及 Glob 在模式、路径或工作目录包含空字节时抛出不明确的错误
- 修复 `apiKeyHelper` 脚本失败被约 10 次静默重试后的通用 401 掩盖的问题；现在 3 次尝试内即会显示脚本自身的错误
- 修复 Bedrock 流式请求在网关转换响应时报出误导性的 "Truncated event message received"——错误信息现在会标明 content-type 并指向代理
- 修复浏览器无法打开时 `/upgrade` 显示登录流程而非升级 URL 的问题
- 修复 Windows 风格 SDK 主机发送空 CRLF 或纯空白行时 stream-json 输入导致会话终止的问题
- 修复 `control_request` 携带非字符串 `set_model` 载荷时，headless stream-json 会话永久挂起的问题；CLI 现在会以错误响应作答
- 修复会话恢复时反复出现 "No completion record was found" 提示的问题——孤立的后续后台任务现在会合并为一条摘要
- 修复 Remote Control 客户端 attach 到终端托管的会话后，在任务开始或结束前看不到后台 agent 和工作流进度的问题
- 修复子 agent 的 `tools` 列表解析为空时 Agent 工具以无工具状态启动的问题——现在会返回明确错误并指出无法识别的条目
- 修复 `/usage` 显示过期缓存柱状图盖过更新数据，以及 `/mcp` 在配置修改后不重新分类占位服务器的问题
- 修复 SDK 主机（如 Claude Desktop）在有后台任务运行的空闲会话上执行 "Change directory" 时报 "A turn is in progress" 失败的问题
- 修复工作流保存对话框在用户级保存时显示 `~/.claude/workflows/` 而非 `CLAUDE_CONFIG_DIR` 位置的问题
- 修复 `/release-notes` 将已查看的说明加入模型上下文的问题——此前 "Show all" 会把整个 changelog 注入后续每次请求
- 修复 agent 视图中发送 peek 回复后粘贴的图片在屏幕生命周期内持续驻留导致的内存泄漏
- 修复插件刷新先于客户端 attach 运行时，SDK 会话丢失通过 initialize 请求定义的 agent 的问题
- 修复长会话中的多个内存泄漏：MCP stdio 服务器的 stderr 每个服务器最多累积 64 MB、LSP 文档无限期保持打开（现改为 LRU 且上限 50 个文档）、后台化后仍保留异步 hook 输出，以及 headless/SDK 会话因大型工具结果载荷无限增长
- 修复使用 offset/limit 读取含超长单行文件时内存暴涨的问题——现在会返回明确的错误而非加载整行
- 修复含大量权限 deny/ask 规则会话中每轮数秒的减速问题——规则匹配器现在只编译一次并缓存
- 修复 sso_region 与 Bedrock 区域不同的 AWS SSO 配置文件下 Bedrock 认证报 "Session token not found or invalid" 失败的问题（2.1.207 回归）
