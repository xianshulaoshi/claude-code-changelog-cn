# Claude Code v2.1.200 更新日志

> 🗓 2026-07-03 发布 · 📋 17 条更新（🔧 2 · 🔄 2 · 🐛 13）

**✨ 本版亮点**

- 🔧 **改进**：权限模式 "default" 更名为 "Manual"，CLI、VS Code 与 JetBrains 全线统一，旧配置仍兼容
- 🔧 **改进**：AskUserQuestion 对话框默认不再自动继续，可通过 /config 开启空闲超时
- 🐛 **关键修复**：修复休眠唤醒后后台会话静默中断、崩溃后后台 agent 永久无法重启等多项稳定性问题
- 🔧 **改进**：优化屏幕阅读器输出，隐藏装饰性符号并将嵌套表格读作简洁标签
- 🐛 **关键修复**：启用终端同步输出，修复 tmux 3.4+ 下的渲染闪烁

**📋 更新明细**（共 17 条，按类别归组）

**🔧 改进**（2 条）

- 改进屏幕阅读器输出：隐藏装饰性符号，将记录符号读作简短标签，嵌套表格读作 `Header: value.` 行
- 改进安装脚本，在安装因系统内存耗尽而被终止时给出解释说明

**🔄 变更**（2 条）

- AskUserQuestion 对话框默认不再自动继续；可通过 `/config` 开启空闲超时
- 在 CLI、`--help`、VS Code 和 JetBrains 中将 "default" 权限模式更名为 "Manual"；`--permission-mode manual` 与 `"defaultMode": "manual"` 仍可与 `default` 一起使用

**🐛 修复**（13 条）

- 修复 `.claude.json` 中 `disabledMcpServers` 或 `enabledMcpServers` 被设为非数组值时启动崩溃的问题
- 修复后台会话在休眠唤醒后或重新打开停滞会话时，在回合中途静默停止的问题
- 修复后台会话在停滞重启后重新执行被 Esc 取消的回合的问题
- 修复崩溃后遗留过期的 `daemon.lock` 且其 PID 被操作系统复用时，后台 agent 永远无法再次启动的问题
- 修复后台 agent 守护进程交接问题：重新安装的旧版本不再能接管守护进程；现在通过版本内嵌的构建时间戳判断版本新旧
- 修复后台 agent 名单（roster）相关问题：瞬时损坏导致孤儿清理被永久禁用、旧版二进制未保留新版写入的字段、以及守护进程重启期间 socket 认证令牌被清除
- 修复子 agent 在输出任何文本前被速率限制截断时返回空结果而非干净失败的问题
- 修复后台 agent 输出中的控制字节进入 agent 视图终端的问题
- 修复 `claude agents --plugin-dir <dir>` 中该标志放在 `agents` 之后时，agent 视图不显示插件的 agents 和 skills 的问题
- 修复项目级插件在同一仓库的 git worktree 中无法正确加载的问题
- 修复 `/mcp` 服务器列表未为屏幕阅读器和放大镜跟踪焦点的问题
- 修复录音未捕获到音频时语音听写显示误导性的 "Voice connection failed" 提示的问题
- 通过启用终端同步输出，修复 tmux 3.4+ 下的渲染闪烁
