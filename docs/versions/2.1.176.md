# Claude Code v2.1.176 更新日志

> 🗓 2026-06-12 发布 · 📋 22 条更新（🚀 1 · 🔧 3 · 🐛 18）

**✨ 本版亮点**

- 🔧 **改进**：会话标题现在跟随对话语言自动生成，可通过 language 设置固定语言
- 🚀 **新功能**：新增 footerLinksRegexes 设置，可在底部状态栏展示正则匹配的链接徽标
- 🐛 **关键修复**：修复 tmux over SSH 下 /copy 与鼠标复制无法进入系统剪贴板的问题
- 🐛 **关键修复**：修复 availableModels 强制失效问题，禁止通过环境变量绕过模型白名单
- 🐛 **关键修复**：修复 Remote Control 静默切换模型、断连原因显示异常及账号切换不清理会话等问题

**📋 更新明细**（共 22 条，按类别归组）

**🚀 新功能**（1 条）

- 新增 `footerLinksRegexes` 设置，支持在底部信息栏显示正则匹配的链接徽标，可通过用户设置或托管设置配置

**🔧 改进**（3 条）

- 会话标题现在按对话语言自动生成（可通过 `language` 设置固定为特定语言）
- 改进 Bedrock 凭证缓存：来自 `awsCredentialExport` 的凭证现在会缓存至其 `Expiration` 时间，而非固定 1 小时
- 后台会话在跨自动更新保留的窗口无法提交回复时现在会显示更清晰的指引，且 `claude daemon status` 会解释版本偏差行为

**🐛 修复**（18 条）

- 修复 `availableModels` 强制失效问题：别名模型选择不再能通过 `ANTHROPIC_DEFAULT_*_MODEL` 环境变量重定向到被禁用的模型，且当 `/fast` 会切换到白名单之外的模型时将拒绝切换
- 修复未启用 Opus 4.8 的组织中 auto 模式在 Fable 5 上失败的问题——分类器现在会回退到可用的最佳 Opus 模型
- 修复 Read/Edit/Write 工具路径的 hook `if` 条件：文档中的模式如 `Edit(src/**)`、`Read(~/.ssh/**)` 和 `Read(.env)` 现在可以正确匹配
- 修复 `.claude/settings.json` 为指向绝对路径的符号链接时 Linux 沙箱无法启动的问题
- 修复 tmux over SSH 环境下 `/copy` 和鼠标选区复制无法到达系统剪贴板的问题，以及 3.2 之前版本 tmux 粘贴缓冲区无法加载的问题
- 修复通过网页/移动端使用 Remote Control 连接时静默切换会话模型的问题
- 修复 Remote Control 断开通知显示裸数字代码而非可读原因的问题，以及连接失败时向对话记录中重复添加一行内容的问题
- 修复登录其他账号时 Remote Control 会话未断开连接的问题
- 修复 `/cd` 和 worktree 移动后会话仍显示先前目录 git 分支的问题
- 修复 `claude agents`：在一个窗口按返回不再导致附加到同一会话的其他窗口脱离
- 修复在回合中执行 `/bg` 后若无剩余任务可继续时，后台会话永远显示“工作中”的问题
- 修复按 PR URL 搜索后台 agent：定时唤醒期间或任务阻塞时打开的 PR 现在会出现在 `claude agents` 搜索结果中
- 修复 Windows 上 agents 视图输入框不显示文本光标的问题
- 修复 `claude --bg -cn <name>` 未设置会话名称的问题
- 修复后台会话在重新拉起前对持久化状态中的 Windows 网络路径进行中和处理
- 修复后台会话重新拉起时因状态文件损坏而拒绝格式错误的 resume ID 的问题
- 修复 `~/.claude/daemon` 设置了 ReadOnly 属性时 Windows 后台服务守护进程无法启动的问题
- 修复云会话在空闲过久后才被认领时因“无法解析认证方式”而失败的问题
