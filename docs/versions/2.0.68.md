**🚀 新功能**（1 条）

**🔧 改进**（1 条）

- 改进计划模式的退出体验：在计划为空或缺失时退出，将显示简化的是/否对话框，而不是抛出错误

- 修复了中文、日文、韩文等语言的 IME（输入法编辑器）支持问题，组合窗口现在会正确定位到光标处
- 修复了被禁用的 MCP 工具仍对模型可见的 bug
- 修复了 subagent 工作期间引导消息可能丢失的问题
- 修复了 Option+方向键按词导航时将整段 CJK（中日韩）文本视为单个单词、而无法按词边界移动的问题
