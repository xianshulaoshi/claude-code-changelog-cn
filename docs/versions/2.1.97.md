# Claude Code v2.1.97 更新日志

> 🗓 2026-04-08 发布 · 📋 46 条更新（🚀 5 · 🔧 13 · 🐛 28）

**✨ 本版亮点**

- 🚀 **新功能**：NO_FLICKER 模式新增焦点视图（Ctrl+O），集中查看提示、工具摘要与最终回复
- 🚀 **新功能**：状态栏支持 refreshInterval 定时刷新，并新增 workspace.git_worktree 信息
- 🐛 **关键修复**：修复 --dangerously-skip-permissions 被静默降级为 accept-edits 的权限问题
- 🐛 **关键修复**：修复 MCP HTTP/SSE 重连时每小时泄漏约 50 MB 缓冲区的内存问题
- 🔧 **改进**：优化日文/中文输入体验：CJK 标点后可直接触发斜杠命令与 @ 补全

**📋 更新明细**（共 46 条，按类别归组）

**🚀 新功能**（5 条）

- 在 NO_FLICKER 模式下新增焦点视图切换（Ctrl+O），可查看提示、带编辑 diffstats 的单行工具摘要以及最终回复
- 新增 status line 的 refreshInterval 设置项，可每 N 秒重新运行状态栏命令
- 在状态栏 JSON 输入中新增 workspace.git_worktree，当当前目录位于关联的 git worktree 内时设置该项
- 在 /agents 中为有活跃子代理实例的代理类型新增 `● N running` 指示器
- 新增 Cedar 策略文件（.cedar、.cedarpolicy）的语法高亮

**🔧 改进**（13 条）

- 改进 Accept Edits 模式：自动批准以安全环境变量或进程包装器为前缀的文件系统命令（如 `LANG=C rm foo`、`timeout 5 mkdir out`）
- 改进 auto 模式与 bypass-permissions 模式：自动批准沙箱网络访问提示
- 改进沙箱：sandbox.network.allowMachLookup 现已在 macOS 上生效
- 改进图片处理：粘贴和附件图片现在会压缩至与 Read 工具读取图片相同的 token 预算
- 改进斜杠命令和 @ 提及补全，在 CJK 句末标点后即可触发，日文/中文输入不再需要在 / 或 @ 前加空格
- 改进 Bridge 会话：在 claude.ai 会话卡片上显示本地 git 仓库、分支和工作目录
- 改进底栏布局：指示器（焦点、通知）现在保持在模式指示行，不再折行到下方
- 改进上下文不足警告：改为临时底栏通知，不再常驻显示
- 改进 markdown 引用块：折行时显示连续的左侧竖线
- 改进会话 transcript 体积：跳过空的 hook 条目并限制存储的编辑前文件副本数量
- 改进 transcript 准确性：每个块的条目现在记录最终 token 用量而非流式占位符
- 改进 Bash 工具的 OTEL 追踪：启用追踪时子进程现在继承 W3C TRACEPARENT 环境变量
- 更新 /claude-api 技能，除 Claude API 外同时覆盖 Managed Agents

**🐛 修复**（28 条）

- 修复 --dangerously-skip-permissions 在批准对受保护路径的写入后被静默降级为 accept-edits 模式的问题
- 修复并加固 Bash 工具权限，收紧对环境变量前缀和网络重定向的检查，并减少常见命令的误弹权限提示
- 修复名称与 JavaScript 原型属性同名（如 toString）的权限规则导致 settings.json 被静默忽略的问题
- 修复管理员移除托管设置中的 allow 规则后，该规则在进程重启前仍然生效的问题
- 修复会话中修改 settings 里 permissions.additionalDirectories 不生效的问题
- 修复从 settings.permissions.additionalDirectories 移除目录后，撤销了通过 --add-dir 传入的同一目录访问权限的问题
- 修复 MCP HTTP/SSE 连接在服务器重连时每小时累积约 50 MB 未释放缓冲区的问题
- 修复 MCP OAuth 的 oauth.authServerMetadataUrl 在重启后的令牌刷新中未生效的问题，解决 ADFS 及类似 IdP 的认证问题
- 修复服务器返回较小 Retry-After 值时 429 重试在约 13 秒内耗尽全部尝试的问题——现在指数退避作为最低等待时间生效
- 修复上下文压缩后速率限制升级选项消失的问题
- 修复多个 /resume 选择器问题：--resume <name> 打开后无法编辑、Ctrl+A 重载清空搜索、空列表吞掉导航、任务状态文本替换会话摘要、以及跨项目数据过期
- 修复 --resume 时被编辑文件超过 10KB 后文件编辑 diff 消失的问题
- 修复 --resume 缓存未命中以及附件消息中丢失的回合中输入未保存到 transcript 的问题
- 修复 Claude 工作期间输入的消息未持久化到 transcript 的问题
- 修复 prompt 类型 Stop/SubagentStop hooks 在长会话中失败的问题，以及 hook 求值器 API 错误显示 "JSON validation failed" 而非实际错误信息的问题
- 修复使用 worktree 隔离或 cwd: 覆盖的子代理将其工作目录泄漏回父会话 Bash 工具的问题
- 修复压缩在 prompt-too-long 重试时写入多 MB 的重复子代理 transcript 文件的问题
- 修复 claude plugin update 对基于 git 的市场插件在远端有更新提交时仍报告 "already at the latest version" 的问题

- 修复 NO_FLICKER 模式下复制折行 URL 时在换行处插入空格的问题
