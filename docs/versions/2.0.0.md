**✨ 本版亮点**

- 🚀 **新功能**：全新原生 VS Code 扩展，Claude Code 深度融入编辑器
- 🚀 **新功能**：新增 /rewind 命令，可回退对话并撤销对应代码改动

- 🔧 **改进**：SDK 正式更名为 Claude Agent SDK，支持 `--agents` 动态添加子代理
- 🐛 **关键修复**：修复 Hooks 中 PostToolUse 缺少 tool_result 块导致的报错
