# Claude Code v2.1.98 更新日志

> 🗓 2026-04-09 发布 · 📋 57 条更新（🚀 7 · 🔧 11 · 🔄 1 · 🐛 38）

**✨ 本版亮点**

- 🚀 **新功能**：新增 Monitor 工具，可实时流式查看后台脚本事件
- 🚀 **新功能**：登录界面新增 Google Vertex AI 交互式配置向导，一站式完成认证与模型配置
- 🐛 **关键修复**：修复多个 Bash 工具权限绕过漏洞，防止任意代码执行风险
- 🔧 **改进**：/agents 改为分页布局，可实时查看运行中的 subagent 并直接运行代理
- 🔧 **改进**：additionalDirectories 权限目录变更即时生效，无需重启会话

**📋 更新明细**（共 57 条，按类别归组）

**🚀 新功能**（7 条）

- 新增 Google Vertex AI 交互式配置向导，可在登录界面选择 "3rd-party platform" 后进入，引导完成 GCP 身份验证、项目与区域配置、凭证校验及模型固定
- 新增 `CLAUDE_CODE_PERFORCE_MODE` 环境变量：启用后，Edit/Write/NotebookEdit 在只读文件上会失败并提示 `p4 edit`，而非静默覆盖
- 新增 Monitor 工具，用于流式获取后台脚本产生的事件
- 新增 Linux 上的子进程沙箱机制：设置 `CLAUDE_CODE_SUBPROCESS_ENV_SCRUB` 后启用 PID 命名空间隔离，并新增 `CLAUDE_CODE_SCRIPT_CAPS` 环境变量限制每会话脚本调用次数
- 新增 `--exclude-dynamic-system-prompt-sections` 标志用于 print 模式，以提升跨用户的提示词缓存命中率
- 在状态栏 JSON 输入中新增 `workspace.git_worktree` 字段，当前目录位于关联 git worktree 内时即会设置
- 启用 OTEL 追踪时，Bash 工具子进程会接收 W3C `TRACEPARENT` 环境变量，使子进程 span 正确挂载到 Claude Code 的追踪树

**🔧 改进**（11 条）

- LSP：Claude Code 现在会在 initialize 请求中通过 `clientInfo` 向语言服务器表明自身身份
- 改进 `/resume` 过滤提示标签，并在过滤指示器中显示项目/worktree/分支名称
- 改进底部指示器（Focus、通知），使其保持在模式指示器行内，而非在窄终端宽度下换行
- 改进 `/agents` 为分页布局：Running 标签页实时显示 subagent，Library 标签页新增运行代理与查看运行实例操作
- 改进 `/reload-plugins`，无需重启即可加载插件提供的技能
- 改进 Accept Edits 模式，自动批准以安全环境变量或进程包装器为前缀的文件系统命令
- 改进 Vim 模式：NORMAL 模式下的 `j`/`k` 现可浏览历史，并在到达输入边界时选中底部胶囊按钮
- 改进转录中的 hook 错误信息，包含 stderr 首行，无需 `--debug` 即可自查
- 改进 OTEL 追踪：并发 SDK 调用时交互 span 现可正确包裹完整轮次，headless 模式按轮次结束 span
- 改进转录条目，携带最终 token 用量而非流式占位符
- 更新 `/claude-api` 技能，除 Claude API 外还涵盖 Managed Agents

**🔄 变更**（1 条）

- 设置 `DISABLE_COMPACT` 时不再显示 `/compact` 提示

**🐛 修复**（38 条）

- 修复 Bash 工具权限绕过漏洞：反斜杠转义的标志可能被误判为只读并自动放行，导致任意代码执行
- 修复复合 Bash 命令在 auto 与 bypass-permissions 模式下绕过强制权限提示的问题，保障安全检查与显式询问规则生效
- 修复带环境变量前缀的只读命令不提示权限的问题，除非该变量为已知安全项（`LANG`、`TZ`、`NO_COLOR` 等）
- 修复重定向到 `/dev/tcp/...` 或 `/dev/udp/...` 时被自动放行而非提示权限的问题
- 修复流式响应卡顿时只会超时的问题，现在会回退到非流式模式
- 修复服务端返回较小 `Retry-After` 时 429 重试在约 13 秒内耗尽全部尝试次数的问题——指数退避现作为最低等待时间生效
- 修复 MCP OAuth 的 `oauth.authServerMetadataUrl` 配置覆盖在重启后的令牌刷新中失效的问题，该问题影响 ADFS 及类似 IdP
- 修复 kitty 键盘协议启用时，xterm 与 VS Code 集成终端中大写字母被丢弃转为小写的问题
- 修复 macOS 文本替换功能删除触发词而非插入替换内容的问题
- 修复通过 Bash 批准对受保护路径的写入后，`--dangerously-skip-permissions` 被静默降级为 accept-edits 模式的问题
- 修复管理员移除托管设置中的允许规则后，规则在进程重启前仍然生效的问题
- 修复 `permissions.additionalDirectories` 变更无法在会话中途生效的问题——移除的目录立即失去访问权限，新增的目录无需重启即可使用
- 修复从 `additionalDirectories` 移除某目录后，通过 `--add-dir` 传入的同一目录访问权限也被一并撤销的问题
- 修复 `Bash(cmd:*)` 与 `Bash(git commit *)` 通配符权限规则无法匹配含多余空格或制表符的命令的问题
- 修复管道命令中混合 `cd` 与其他片段时，`Bash(...)` 拒绝规则被降级为提示确认的问题
- 修复 `cut -d /`、`paste -d /`、`column -s /`、`awk '{print $1}' file` 及文件名含 `%` 时误触发 Bash 权限提示的问题
- 修复名称与 JavaScript 原型属性（如 `toString`）相同的权限规则导致 `settings.json` 被静默忽略的问题
- 修复使用 `--dangerously-skip-permissions` 时，agent 团队成员未继承领导者权限模式的问题
- 修复全屏模式下悬停在 MCP 工具结果上时的崩溃问题
- 修复全屏模式下复制换行 URL 时在断行处插入空格的问题

- 修复多个 `/resume` 选择器问题：`--resume <name>` 打开后不可编辑、过滤重载清除搜索状态、空列表吞掉方向键、跨项目数据陈旧、以及瞬态任务状态文本取代对话摘要
- 修复 `/export` 不支持绝对路径与 `~`，并将用户指定的扩展名静默改写为 `.txt` 的问题

- 修复消息重新挂载后速率限制升级提示文本被隐藏的问题

- 修复 `DISABLE_AUTOUPDATER` 在基于 npm 的安装上未完全抑制 npm registry 版本检查与符号链接修改的问题
