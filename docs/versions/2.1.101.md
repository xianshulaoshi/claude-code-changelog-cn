**📋 更新明细**（共 46 条，按类别归组）

**🚀 新功能**（2 条）

- 新增 `/team-onboarding` 命令，可基于本地 Claude Code 使用记录生成队友上手指南
- 默认信任操作系统 CA 证书库，企业 TLS 代理无需额外配置即可正常工作（设置 `CLAUDE_CODE_CERT_STORE=bundled` 可仅使用内置 CA）

**🔧 改进**（13 条）

- `/ultraplan` 及其他远程会话功能现在会自动创建默认云环境，不再需要先在网页端完成设置
- 改进 brief 模式：当 Claude 返回纯文本而非结构化消息时会自动重试一次
- 改进 focus 模式：Claude 现在知道用户只能看到其最终消息，会撰写更完整的自包含摘要
- 改进工具不可用错误提示：当模型调用了存在但在当前上下文不可用的工具时，会解释原因及后续处理方式
- 改进速率限制重试提示：显示触发的是哪项限制及何时重置，而非不透明的倒计时秒数
- 改进拒绝错误消息：在 API 提供说明时会包含该说明
- 改进 `claude -p --resume <name>`，现在接受通过 `/rename` 或 `--name` 设置的会话标题
- 改进设置容错性：`settings.json` 中出现无法识别的 hook 事件名不再导致整个文件被忽略
- 改进插件 hook：由托管设置强制启用的插件，在设置了 `allowManagedHooksOnly` 时其 hook 也会执行
- 改进 `/plugin` 和 `claude plugin update`：当无法刷新 marketplace 时会显示警告，而非静默报告过期版本
- 改进 plan 模式：当用户所属组织或认证配置无法访问 Claude Code on the web 时，隐藏 "Refine with Ultraplan" 选项
- 改进 beta 追踪功能：遵循 `OTEL_LOG_USER_PROMPTS`、`OTEL_LOG_TOOL_DETAILS` 和 `OTEL_LOG_TOOL_CONTENT`；除非主动开启，不再输出敏感的 span 属性
- 改进 SDK `query()`：当使用方从 `for await` 中 `break` 或使用 `await using` 时，会清理子进程和临时文件

**🐛 修复**（31 条）

- 修复 LSP 二进制检测所用的 POSIX `which` 回退逻辑中的命令注入漏洞
- 修复内存泄漏：长会话此前会在虚拟滚动器中保留数十份历史消息列表副本
- 修复 `--resume`/`--continue` 在大会话中丢失对话上下文的问题，此前加载器会锚定在死分支而非活跃对话上
- 修复 `--resume` 链恢复问题：此前当子代理消息落在主链写入间隙附近时，会错误地桥接到无关的子代理对话
- 修复 `--resume` 在持久化的 Edit/Write 工具结果缺少 `file_path` 时崩溃的问题
- 修复硬编码的 5 分钟请求超时问题：此前无论 `API_TIMEOUT_MS` 如何设置，慢速后端（本地 LLM、extended thinking、慢速网关）都会被中断
- 修复 `permissions.deny` 规则无法覆盖 PreToolUse hook 的 `permissionDecision: "ask"` 的问题——此前 hook 可能将拒绝降级为提示
- 修复 `--setting-sources` 不含 `user` 时，后台清理忽略 `cleanupPeriodDays` 并删除 30 天前的对话历史的问题
- 修复 Bedrock SigV4 认证问题：当 `ANTHROPIC_AUTH_TOKEN`、`apiKeyHelper` 或 `ANTHROPIC_CUSTOM_HEADERS` 设置了 Authorization 头时返回 403
- 修复 `claude -w <name>` 在上一次会话的 worktree 清理遗留过期目录后报 "already exists" 失败的问题
- 修复子代理无法继承动态注入服务器的 MCP 工具的问题
- 修复在隔离 worktree 中运行的子代理被拒绝读取/编辑其自身 worktree 内文件的问题
- 修复沙箱化 Bash 命令在系统刚启动后因 `mktemp: No such file or directory` 失败的问题
- 修复 `claude mcp serve` 在校验 `outputSchema` 的 MCP 客户端中工具调用报 "Tool execution failed" 的问题
- 修复 `RemoteTrigger` 工具的 `run` 动作发送空请求体被服务器拒绝的问题
- 修复多个 `/resume` 选择器问题：窄屏默认视图隐藏其他项目的会话、Windows Terminal 上无法进入预览、worktree 中 cwd 不正确、会话未找到错误未输出到 stderr、终端标题未设置、以及 resume 提示与输入框重叠
- 修复 Grep 工具在内置 ripgrep 二进制路径失效时报 ENOENT 的问题（VS Code 扩展自动更新、macOS App Translocation）；现在会回退到系统 `rg` 并在会话中自愈
- 修复 `/btw` 每次使用时都将整个对话副本写入磁盘的问题
- 修复 `/context` 的剩余空间和消息明细与头部百分比不一致的问题
- 修复多个插件问题：斜杠命令在 `name:` frontmatter 重复时解析到错误插件、`/plugin update` 报 `ENAMETOOLONG`、Discover 显示已安装的插件、目录来源插件从过期版本缓存加载、以及 skills 不遵循 `context: fork` 和 `agent` frontmatter 字段
- 修复 `/mcp` 菜单为配置了 `headersHelper` 的 MCP 服务器提供 OAuth 专属操作的问题；现在改为提供 Reconnect 以重新调用 helper 脚本
- 修复 `ctrl+]`、`ctrl+\` 和 `ctrl+^` 快捷键在发送原始 C0 控制字节的终端（Terminal.app、默认 iTerm2、xterm）中不触发的问题
- 修复 `/login` OAuth URL 渲染时带有填充、导致无法干净地用鼠标选中的问题
- 修复多个渲染问题：非全屏模式下可见区域上方内容变化时的闪烁、非全屏模式长会话中终端回滚缓冲被清空、以及鼠标滚动转义序列偶尔作为文本泄漏到输入提示中
- 修复 `settings.json` 中环境变量值为数字而非字符串时崩溃的问题
- 修复应用内设置写入（如 `/add-dir --remember`、`/config`）未刷新内存快照的问题，该问题导致已移除的目录无法在会话中被撤销
- 修复自定义快捷键（`~/.claude/keybindings.json`）在 Bedrock、Vertex 及其他第三方提供商上不加载的问题
- 修复 `claude --continue -p` 无法正确继续由 `-p` 或 SDK 创建的会话的问题
- 修复多个 Remote Control 问题：会话崩溃时 worktree 被移除、连接失败未持久化到 transcript、brief 模式下本地会话显示虚假的 "Disconnected" 指示、以及仅设置 `CLAUDE_CODE_ORGANIZATION_UUID` 时 `/remote-control` 无法通过 SSH 连接
- 修复 `/insights` 有时在响应中遗漏报告文件链接的问题
- [VSCode] 修复关闭最后一个编辑器标签页时聊天输入框下方的文件附件未清除的问题
