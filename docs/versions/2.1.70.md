# Claude Code v2.1.70 更新日志

> 🗓 2026-03-06 发布 · 📋 29 条更新（🚀 3 · 🔧 6 · 🐛 20）

**✨ 本版亮点**

- 🚀 **新功能**：VS Code 新增活动栏 spark 图标查看所有会话，计划可全文档浏览并加评论反馈
- 🚀 **新功能**：VS Code 新增原生 MCP 管理界面，/mcp 可启停服务器、重连及管理 OAuth
- 🔧 **改进**：压缩（compaction）保留图片以复用提示缓存，压缩更快更省成本
- 🔧 **改进**：输入重渲染减少约 74%，回话恢复每次省约 600 tokens
- 🐛 **关键修复**：修复第三方网关（ANTHROPIC_BASE_URL）API 400 及自定义 Bedrock 模型的 effort 参数报错

**📋 更新明细**（共 29 条，按类别归组）

**🚀 新功能**（3 条）

- [VSCode] VS Code 活动栏新增 spark 图标，列出所有 Claude Code 会话，会话以完整编辑器形式打开
- [VSCode] VS Code 新增计划的完整 markdown 文档视图，支持添加评论提供反馈
- [VSCode] 新增原生 MCP 服务器管理对话框——在聊天面板中使用 `/mcp` 即可启用/禁用服务器、重连及管理 OAuth 认证，无需切换到终端

**🔧 改进**（6 条）

- 改进麦克风采集静音时的错误提示，以便与 "未检测到语音" 区分
- 改进压缩（compaction）以在摘要请求中保留图片，从而复用提示缓存，使压缩更快、成本更低
- 改进 `/rename`，现在可在 Claude 处理过程中使用，不再被静默排队
- 回合期间提示输入的重渲染减少约 74%
- 为无自定义 CA 证书的用户减少约 426KB 的启动内存占用
- 连接期间将 Remote Control `/poll` 频率降低为每 10 分钟一次（原为 1–2 秒），服务器负载降低约 300 倍。重连不受影响——传输丢失会立即唤醒快速轮询

**🐛 修复**（20 条）

- 修复使用 `ANTHROPIC_BASE_URL` 搭配第三方网关时的 API 400 错误——工具搜索现在能正确检测代理端点并禁用 `tool_reference` 块
- 修复使用自定义 Bedrock 推理配置文件或不匹配标准 Claude 命名模式的模型标识符时报 `API Error: 400 This model does not support the effort parameter` 的问题
- 修复 `ToolSearch` 之后模型返回空响应的问题——服务器在提示词尾部以系统提示风格的标签渲染工具 schema，可能误导模型提前停止
- 修复带 `instructions` 的 MCP 服务器在首轮对话后连接时破坏提示缓存的问题
- 修复通过慢速 SSH 连接输入时 Enter 键插入换行而非提交的问题
- 修复 Windows/WSL 上剪贴板损坏非 ASCII 文本（CJK、emoji）的问题，改用 PowerShell `Set-Clipboard`
- 修复 Windows 上从 VS Code 集成终端启动时额外打开 VS Code 窗口的问题
- 修复 Windows 原生二进制上语音模式失败并报 "native audio module could not be loaded" 的问题
- 修复设置 `voiceEnabled: true` 时会话启动后按住说话无法激活的问题
- 修复包含 `#NNN` 引用的 markdown 链接错误指向当前仓库而非所链接 URL 的问题
- 修复项目 `.claude/settings.json` 固定了旧版 Opus 模型字符串时反复弹出 "Model updated to Opus 4.6" 通知的问题
- 修复插件在 `/plugin` 中显示为不准确安装状态的问题
- 修复插件在全新启动时报 "not found in marketplace" 错误的问题，市场安装后会自动刷新
- 修复 `/security-review` 命令在旧版 git 上因 `unknown option merge-base` 失败的问题
- 修复 `/color` 命令无法恢复默认颜色的问题——`/color default`、`/color gray`、`/color reset` 和 `/color none` 现在均可恢复默认
- 修复 `AskUserQuestion` 预览对话框的性能回退问题，此前备注输入框每次按键都会重新渲染 markdown
- 修复启动早期读取的功能开关从不刷新磁盘缓存、导致过期值跨会话残留的问题
- 修复 Claude Code Remote 环境中应用 `acceptEdits` 或 `plan` 之外的 `permissions.defaultMode` 设置值的问题——这些值现在会被忽略
- 修复技能列表在每次 `--resume` 时重复注入的问题（每次恢复约节省 600 tokens）
- 修复 VS Code teleport 会话中传送标记不渲染的问题
