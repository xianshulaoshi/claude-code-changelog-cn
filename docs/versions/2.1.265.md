# Claude Code v2.1.265 更新日志

> 🗓 2026-09-08 发布 · 📋 50 条更新（🚀 4 · 🔧 8 · 🔄 4 · 🐛 34）

**✨ 本版亮点**

- 🚀 **新功能**：支持 --plugin-dir 指向插件文件夹，运行中新增或移除的子插件可自动识别
- 🔧 **改进**：输入斜杠命令时改为列表匹配展示，插件技能可直接用简名找到
- 🔧 **改进**：大幅加快长会话恢复速度，大仓库下 --worktree 启动也更快
- 🐛 **关键修复**：修复非交互会话每条消息重置 shell 工作目录的问题，cd 现在可跨轮次保留
- 🐛 **关键修复**：修复旧版 HTTP+SSE 传输的 MCP 服务器无法连接的问题，自动回退到 SSE

**📋 更新明细**（共 50 条，按类别归组）

**🚀 新功能**（4 条）

- 在 Claude Desktop 和 Cowork 通过 Claude apps 网关发送的遥测数据中新增 `user.email` 和 `user.groups`，与终端会话保持一致
- 支持将 `--plugin-dir` 指向一个包含多个插件的文件夹：每个含 manifest 的子文件夹都会加载，且运行期间新增或移除的子插件会被自动识别
- 为保存到磁盘的工具结果新增 1 GB 上限；会话内预览会标注已保存的文件何时被截断
- [VSCode] 新增对闲置一段时间（可在新设置 "Archive inactive sessions" 中配置，默认 14 天）的会话的自动归档

**🔧 改进**（8 条）

- 改进大仓库上的 `--worktree` 启动速度：新 worktree 现在会并行检出（git 2.32+）
- 改进 `/workflows` agent 详情：工具调用会标记为运行中、失败或完成，subagent 有任务列表时会显示，Enter 可展开列出的调用及其输入和结果
- 改进在提示中输入斜杠命令的体验：匹配项现在以列表展示（非全屏下 Tab 打开列表）而非单一建议，插件技能现在可通过简名找到
- 改进需要登录的远程 MCP 服务器：Claude Code 现在在你实际完成身份验证前不会向其注册 OAuth 客户端
- 加快读取了大量文件的长会话的恢复速度
- 改进超出大小限制的图片无法解码时的错误提示：现在会说明原因及解决方法，而不仅是引用限制
- 改进 Artifact 工具对他人写入的 artifact 的读取：摘要现在将该页面视为不可信内容并标记其中的嵌入指令，而非直接转述
- 更新 `.claude` 文件夹权限选项的描述，说明其实际允许的范围：在会话中编辑项目 `.claude` 文件夹（或 `~/.claude`）中的文件

**🔄 变更**（4 条）

- 变更：托管设置中含 `forceLoginGatewayUrl` 的机器现在从启动起即为 Claude apps 网关会话，与 `forceLoginMethod: "gateway"` 一致；遗留的 claude.ai 登录或 API key 将不再使用
- 变更：图像处理改用运行时内置的图像支持；CLI 不再将原生图像模块解压到临时目录
- 变更：插件显示元数据在 Installed 标签页和 `claude plugin details` 中优先使用市场条目，缺失部分从 `plugin.json` 补全
- 变更：Claude apps 网关会话现在直接将 OpenTelemetry 导出到网关托管设置在 `OTEL_EXPORTER_OTLP_ENDPOINT` 中指定的收集器，而非通过网关中继；未指定收集器的会话仍使用中继

**🐛 修复**（34 条）

- 修复恢复前台启动的 subagent 时更改其工具列表和 system prompt 前缀的问题，该问题会破坏该 agent 的 prompt 缓存复用
- 修复 agent 队友和已恢复的 subagent 在后续轮次中将 SubagentStart hook 上下文和预加载技能移出 prompt 前缀的问题，该问题会破坏 prompt 缓存复用
- 修复上一个进程在工具运行期间退出后的恢复行为：不再重写最后一条提示，被中断的工具调用会被保留并标记为已中断
- 修复 `/model opusplan[1m]` 被拒绝并提示 "Model not found" 的问题
- 修复权限提示和消息中的语法高亮代码有时会丢失 Ruby `?`、Erlang `$` 或 Perl `$` sigil 后一个字符的问题
- 修复全屏转录界面在斜杠命令或 @-文件建议列表打开或关闭时跳动一行的问题
- 修复包含反斜杠的插件路径在 macOS 和 Linux 上绕过符号链接包含性检查的问题
- 修复名称以两个点开头的插件目录被错误拒绝为位于插件根目录之外的问题
- 修复 VS Code 和 SDK 会话在刷新令牌期间关闭会话后偶尔需要重新登录的问题
- 修复 Remote Control 会话在回复的最后一条消息之前发送轮次结束信号的问题，该问题可能导致 Claude 应用在回复最后一部分到达前就显示已完成
- 修复后台（`--bg`）会话在空闲超时前一刻收到消息时偶尔在轮次中途被回收的问题
- 修复 Claude Code 自身的 git status 和 diff 探测会运行工作树内嵌套仓库配置的 clean filter 的问题
- 修复 advisor 工具及其指令按每次请求的模型重新决定的问题；现在该决定只做一次，且变化时会在会话中公布
- 修复 artifact publish 接受连接器未暴露的工具名的问题；当声明的工具全部不存在时现在会拒绝发布，部分不存在时会给出警告
- 修复 `/add-dir <subdirectory>` 在托管设置仅锁定技能到插件时拒绝加载子目录的 agents，以及仅锁定 agents 时却承诺加载 agents 的问题
- 修复双键快捷键在第二个按键超过一秒后才到达时（如 tmux 内）静默取消的问题；现在会等待 3 秒，超时时显示提示
- 修复分支技能（`context: fork`）不在 stream-json 中流式传输其启动提示，以及 `--forward-subagent-text` 下其文本轮次不作为进度事件的问题
- 修复插件默认组件文件夹因操作系统无法检查（如符号链接循环）而被静默跳过的问题；现在会在 `/plugin` 中报告并附带错误代码
- 修复 Claude apps 网关的 OTLP 遥测中继在收集器拒绝少量格式错误或过大的载荷后暂停所有转发 30 秒的问题
- 修复 `/plugin` Discover/Browse 和 `claude plugin list --json --available` 对元数据仅存在于 `plugin.json` 的市场插件不显示描述或显示名称的问题
- 修复 `/login` 在已通过托管设置的 Claude apps 网关登录的会话中重新运行时显示 "no gateway URL is configured" 的问题
- 修复 `/model` 在设置文件无法写入时仍声称模型"已保存为默认值"的问题；现在会提示保存失败及原因
- 修复 Remote Control 的 `/clear` 需等待 SessionStart hooks 和已打开的终端对话框才能完成的问题
- 修复 `/config` 对话框在标签页之间切换时高度变化的问题
- 修复容器重启后恢复 workflow run 的问题；run journal 缺失时恢复现在会以明确错误失败，而不是重新运行所有 agent
- 修复 `claude-api` 技能的错误码参考：模型访问失败返回 404，不可用的 beta 头返回 400，而非 403
- 修复非交互会话（`-p` 配合 stream-json 输入、Agent SDK、云会话）在每个新用户消息时重置 shell 工作目录的问题；`cd` 现在可跨轮次保留
- 修复配置为 `http` 但仅支持旧版 HTTP+SSE 传输的 MCP 服务器永远无法连接的问题；Claude Code 现在会按 MCP 规范回退到 SSE
- 修复云会话中部分 claude.ai 连接器（对不支持的请求返回 HTTP 401 的服务器）虽已在 claude.ai 连接却仍显示需要身份验证的问题
- 修复远程会话在等待连接器审批或登录链接期间保持 sandbox 容器存活的问题
- 修复恢复的会话在"后台任务未完成"通知中显示冗长的面向模型的恢复指令，而不是简短状态行的问题
- Windows：修复在 AppContainer 或受限令牌沙箱内运行时 Read、Write 和 Edit 拒绝所有文件（"symlink resolution changed after permission was checked"）的问题
- [VSCode] 修复会话打开超过 10 分钟后，Reload Window 或重启后侧边栏聊天显示空白的问题
- [VSCode] 修复 "Remote Control is active" 消息上时间线圆点位于文字下方的问题
