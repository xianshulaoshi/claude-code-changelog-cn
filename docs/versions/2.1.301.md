# Claude Code v2.1.301 更新日志

> 🗓 2026-10-15 发布 · 📋 51 条更新（🚀 8 · 🔧 4 · 🔄 2 · 🐛 37）

**✨ 本版亮点**

- 🚀 **新功能**：vim 模式新增 % 匹配括号跳转，可单独使用或与 d/c/y 组合
- 🔧 **改进**：切换到更小上下文窗口的模型时，会先由原模型总结对话再切换，避免浪费额度
- 🐛 **关键修复**：修复会话在 LLM 网关下被未选定的模型反复压缩的问题
- 🐛 **关键修复**：修复登录令牌刷新被打断导致的超时和意外登出
- 🚀 **新功能**：[VSCode] Claude 回复支持 LaTeX 数学公式渲染

**📋 更新明细**（共 51 条，按类别归组）

**🚀 新功能**（8 条）

- 新增 `CLAUDE_CODE_RETRY_WATCHDOG_MAX_USAGE_LIMIT_WAIT_MS`，使无人值守重试模式（`CLAUDE_CODE_RETRY_WATCHDOG`）在用量限额重置时间过远时直接结束请求，而不是一直等待
- 为 `claude-api` skill 新增 OpenTelemetry 追踪指南，包括使用 `ant` CLI 配置追踪目的地
- vim 模式新增 `%` 动作：跳转到匹配的括号，可单独使用或与 d/c/y 组合
- 为 mod 的 `Input` 新增 `rows`：终端中的多行文本框，Enter 提交，Shift+Enter 或 Enter 前加反斜杠可换行
- OpenTelemetry `tool_decision` 事件新增 `classifier_verdict` 和 `permission_mode`，可区分自动模式分类器决策与权限规则
- OpenTelemetry `tool_decision` 事件新增 `classifier_category`，在 `OTEL_LOG_TOOL_DETAILS=1` 时标明分类器拦截所匹配的内置规则名称
- [VSCode] 新增 Claude 回复中的 LaTeX 数学公式渲染，支持 `$$` 和多行 `\[ … \]` 块以及行内 `$…$` 和 `\(…\)` 数学
- [VSCode] 在 VS Code 和 JetBrains 面板中为 Pro 和 Max 计划的用量限额横幅新增 "Get more usage" 链接

**🔧 改进**（4 条）

- 改进切换到上下文窗口更小的模型的体验：过长的对话现在会先由前一个模型总结
- 改进长时间运行的 subagent 工作时的渲染性能：其进度轨迹现在增量更新，而不是每次渲染都完整重新处理
- 改进 artifacts：Claude 写入的页面现在会绘制吸顶 header 上方的区域，滚动文本不再出现在移动应用的该区域
- 改进 mods：在 VS Code 以及桌面和移动应用中，问题对话框上方绘制的树现在可包含 Markdown 且最多 48 行；终端保持 12 行纯文本

**🔄 变更**（2 条）

- 变更 mod hook 的 `.catch` 处理器仅在 hook 抛出异常或超时时运行；hook 自身调用之下引发的事件现在会跳过该 hook 而不询问其 `.catch`
- 变更 mod 的 `$.env.set` 在变量设置或取消后以 `{}` 结束；写入未执行时以 `{ deny }` 结束并说明原因

**🐛 修复**（37 条）

- 修复退出时未加询问即删除由 `WorktreeCreate` hook 创建的 worktree 的问题（该 worktree 可能包含未推送的提交）
- 修复当最新的 Fable 模型对你的组织不可用时，`fable`（及 `best`）模型别名在 Anthropic API 上报错的问题：Claude Code 现在会自动重试上一个 Fable 模型一次
- 修复磁盘已满导致登录无法刷新时出现误导性的 "Please run /login" 错误；现在错误信息会指明磁盘问题并提示删除文件
- 修复 Grep 和 Glob 在搜索程序于返回结果前意外失败时报告无匹配的问题；现在会返回搜索失败的错误
- 修复 workflow agent 在读取到其任务文本不含用户授权的 harness 说明后有时跳过步骤、且运行仍报告成功的问题
- 修复 PreToolUse hook 覆盖 Edit 或 Write 时 artifact 更新被拒绝的问题；Claude 现在会先编辑文件再重新发布，而不是在发布调用中修改
- 修复参数名过多或过长的 skills 和 commands 在调用时卡顿数秒的问题；现在只填充前 64 个名称，每个最长 64 字符
- 修复 skills、commands 和 hooks 在参数填充大量占位符时占用过多内存的问题
- 修复基于 0.53 之前 VTE 的终端（如 RHEL 8 上的 MATE Terminal）中杂散字符（如 `>0q`）遮挡文件夹信任提示、退出时 shell 提示符前出现 `>4m` 的问题
- 修复某些版本的 iTerm2 中启动时提示符出现杂散 `GOK` 文本的问题
- 修复切换到名称含 `application-inference-profile` 的模型时，在提供方不是 Bedrock 的情况下也会运行 `awsAuthRefresh` 命令并延迟模型切换 hook 的问题
- 修复 `claude auth status` 或 `claude plugin list` 等短命令在令牌刷新过程中退出后，导致登录刷新超时和意外登出的问题
- 修复在权限检查期间被回合中发送的消息打断的工具调用被错误上报为被用户拒绝的问题
- 修复切换到上下文窗口更小的模型时，可能未经询问就由前一个模型消耗用量额度进行总结的问题
- 修复在 LLM 网关返回的响应所标模型与请求不符时，会话被未选定的模型反复压缩的问题
- 修复 vim 模式在缓慢或繁忙的机器上有时按 Escape 后仍停留在 INSERT 模式的问题
- 修复 vim 模式下 Esc 丢弃已输入的 AskUserQuestion 答案的问题：自由文本框现在支持 vim NORMAL 模式，Esc 仅在 NORMAL 模式下取消
- 修复 Read 工具将 .xlsm、.parquet、.epub 和 .heic 等二进制文件当作文本读取的问题
- 修复仅含表头的 Markdown 表格在超出终端宽度时什么都不显示的问题（包括计划审批卡片中的计划）
