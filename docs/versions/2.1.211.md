# Claude Code v2.1.211 更新日志

> 🗓 2026-07-15 发布 · 📋 37 条更新（🚀 1 · 🔧 9 · 🔄 3 · 🐛 24）

**✨ 本版亮点**

- 🔧 **改进**：后台代理结果更可靠：等待真实完成并汇报仍在运行的代理状态，不再编造结果
- 🐛 **关键修复**：修复 Bedrock、Vertex 等平台的提示缓存回归，避免系统上下文被重复计费
- 🐛 **关键修复**：修复多个会话唤醒后同时登出的问题，共享凭证也能保持登录状态
- 🔧 **改进**："always allow" 权限规则改存于仓库根目录，在 git worktree 中跨会话生效
- 🐛 **关键修复**：修复自动模式覆盖 PreToolUse hook 的 ask 决策，hook 审批提示现在生效

**📋 更新明细**（共 37 条，按类别归组）

**🚀 新功能**（1 条）

- 新增 `--forward-subagent-text` 标志和 `CLAUDE_CODE_FORWARD_SUBAGENT_TEXT` 环境变量，可在 stream-json 输出中包含子代理的文本与思考内容

**🔧 改进**（9 条）

- 加固了 Windows 上同步的技能/插件目录命名，并保持 CCR 的 web fetch/search 代理在 `/clear` 后正常工作
- 改进终端布局与渲染性能
- 改进后台代理结果报告——Claude 现在会汇报仍在运行的代理状态并等待真正完成，而不是编造结果
- 改进内存索引超限警告，仅统计已加载内容，排除 frontmatter 和 HTML 注释
- 更新整数环境变量（超时、token 预算、重试次数），现在支持 `1e6` 和 `64_000` 等科学计数法与数字分隔符写法
- 更新文档链接指向当前文档站点
- [VSCode] 更新 Remote Control 横幅，说明其功能
- Claude in Chrome：加固文件上传路径校验
- Claude in Chrome：截图操作的 `save_to_disk` 现在会将图片写入磁盘并返回路径；此前该操作无效

**🔄 变更**（3 条）

- 变更 "always allow" 权限规则保存至仓库根目录，使在 git worktree 中授予的批准可跨会话和 worktree 持久生效
- 变更 `/usage-credits`，在向组织管理员发送请求前先请求确认
- 变更 Vim 模式 `s` 和 `S`（替换字符/行）使其在 NORMAL 模式下可用，与 vim 行为一致

**🐛 修复**（24 条）

- 修复转发到聊天渠道的权限预览未中和双向覆盖、零宽和形似引号字符的问题，使工具输入无法在视觉上篡改审批消息
- 修复自动模式覆盖 PreToolUse hook 对非沙箱 Bash 的 `ask` 决策的问题——现在 hook 的 `ask` 决策至少会触发一次提示
- 修复多个并行 Claude Code 会话共享同一凭证存储时，从睡眠唤醒后全部同时登出的问题
- 修复插件 MCP 服务器在空闲 Web 会话唤醒后不再重连、导致 MCP 调用在下一条消息前持续失败的问题
- 修复 Vertex 和 Bedrock 上的 Claude Code 在显式配置模型时仍尝试默认 Opus 模型并打印多余回退提示的问题
- 修复以显式模型覆盖启动的子代理在恢复或收到后续消息时回退到父代理模型的问题
- 修复嵌套的 `.claude/rules/*.md` 文件在设置来源排除项目设置时仍被加载的问题
- 修复文件上传校验：以 DOS 设备后缀（`.prn`）或结尾句点结尾的文件名现在可被接受，含多个硬链接的文件将被拒绝
- 修复从远程和 CLI 会话向 Chrome 中的 Claude 上传文件的问题
- 修复输入为 "?" 的编辑内容被静默吞掉并切换快捷键面板的问题
- 修复启用 Claude in Chrome 扩展但 Chrome 未运行时的启动挂起问题
- 修复 300ms 延迟才显示异步内容（Settings 标签页、Stats、diff 视图及其他加载状态）的问题
- 修复从代理视图重新打开刚停止的后台会话时以相同会话 id 启动空白对话的问题
- 修复 `/loop` 使用一次后导致会话在 `/resume` 中不可见的问题
- 修复屏幕阅读器用户在 `/terminal-setup` 或引导流程终端设置后失去可听终端铃声的问题
- 修复使用 LLM 网关认证（`ANTHROPIC_AUTH_TOKEN` + `ANTHROPIC_BASE_URL`）的后台任务在守护进程重启后返回 "Not logged in" 的问题
- 修复 `claude agents` 任务在 git 不再识别其工作树时变得永久无法删除的问题——该行现在会显示删除被拒绝的原因，而不是静默重新出现
- 修复 `/clear` 不重置会话费用计数器的问题——现在 `/clear` 后状态栏费用从 $0 开始
- 修复 Windows 上 Claude in Chrome 设置页面无法在浏览器中打开的问题
- 修复 Windows 上无头打印模式会话在 stdin 不可读时崩溃或静默退出的问题
- 修复代理视图中后台会话标题在提示词包含链接时显示命名模型的拒绝文本的问题
- 修复被用户终止的后台代理自动重生的问题，以及复活的代理重新运行旧会话中过期提示词的问题
- 修复无计划时间的例程显示下一次运行时间为公元 1 年的问题
- 修复 Bedrock、Vertex、Mantle 和 Foundry 上的提示缓存回归，该回归导致每次请求都将尾部系统上下文块作为新输入 token 计费
