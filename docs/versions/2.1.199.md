# Claude Code v2.1.199 更新日志

> 🗓 2026-07-02 发布 · 📋 24 条更新（🔧 4 · 🐛 20）

**✨ 本版亮点**

- 🚀 **新功能**：斜杠技能可堆叠调用，如 `/skill-a /skill-b do XYZ`，一次加载前 5 个技能
- 🔧 **改进**：订阅用户遇到临时 429 限流错误将自动退避重试，不再导致本轮对话失败
- 🐛 **关键修复**：修复 Linux 后台代理守护进程在异常关闭后每 50 秒自杀并杀死所有运行中代理
- 🐛 **关键修复**：修复流式响应中途遇服务端错误时被丢弃，现在保留已生成的部分内容
- 🐛 **关键修复**：修复子代理静默吞掉 API 错误甚至误报成功，错误现在会正确上报给父代理

**📋 更新明细**（共 24 条，按类别归组）

**🔧 改进**（4 条）

- 堆叠的斜杠技能调用（如 `/skill-a /skill-b do XYZ`）现在会加载全部前置技能（最多 5 个），而不再只加载第一个
- 订阅用户遇到临时服务端限流错误（与你的用量上限无关的 429）现在会自动退避重试，而不再使本轮对话失败
- `CLAUDE_CODE_RETRY_WATCHDOG` 现在将非容量类临时错误的默认重试次数提升至 300，并取消了 `CLAUDE_CODE_MAX_RETRIES` 15 次的上限
- `claude agents` 会话行中的拉取请求链接现在显示为简洁的 `#N`，不再带有冗余的 "PR" 标签

**🐛 修复**（20 条）

- 修复 SSL 证书错误（TLS 拦截代理、缺少 `NODE_EXTRA_CA_CERTS`、证书过期）反复消耗重试次数后才给出可操作的提示的问题——现在会立即失败并附带修复提示
- 修复 API 在部分输出后于流中途返回 overloaded/服务端错误时流式响应被丢弃的问题——现在会保留部分输出并附带未完成响应提示
- 修复子代理被限流或服务端错误中断时静默失败、不向父代理返回已完成部分工作的问题
- 修复子代理将 API 错误（如达到用量上限）误报为成功结果的问题——错误现在会上报给父代理
- 修复 Linux 上后台代理守护进程在异常关闭留下损坏的 worker 记录后，每隔约 50 秒杀死自身及所有运行中代理的问题
- 修复后台代理在 macOS 上通过 SSH 冷启动时失败并报 "Could not switch to audit session" 的问题（2.1.196 引入的回归）
- 修复 `claude stop` 与后台代理重启竞争时被静默撤销的问题——重启现在会遵守停止指令
- 修复后台任务运行长时间命令时进度指示器停滞数分钟的问题
- 修复内存不足机器上的后台会话只显示通用错误的问题——现在会提示内存不足并建议释放资源
- 修复后台代理完成时远程会话在代理视图中于 Working 和 Idle 之间短暂抖动的问题
- 修复其他子代理仍在工作时空闲子代理从代理面板中消失的问题；多余的空闲代理现在会折叠为一个可展开的摘要行
- 修复查看子代理时输入 `/model` 或 `/fast` 会静默打开主代理模型选择器的问题——现在会提示该命令作用于主代理
- 修复 `SessionStart`、`Setup` 和 `SubagentStart` hooks 以退出码 2 退出时静默隐藏 stderr 的问题——错误现在会显示在会话记录中
- 修复 `claude --dangerously-skip-permissions daemon <subcommand>` 被当作聊天提示而非执行子命令的问题
- 修复重新生成的代理复用先前代理名称时 `SendMessage` 静默错误路由的问题——工具现在会检测不匹配并要求调用方重新指定目标
- 修复打开或恢复无新消息的会话时不必要地增大会话记录文件的问题
- 修复通过 `←` 或 `/background` 将会话转为后台时代理视图行丢失其 `/color` 的问题
- 修复从启动恢复对话框重置损坏的配置文件时将其彻底破坏无法恢复的问题——现在会先备份该文件
- 修复 Claude in Chrome 在来自不同构建或配置目录的会话运行时反复打开重连页面的问题
- 修复计划模式不提示有状态的浏览器工具调用的问题；只读的 `browser_batch` 调用现在会被正确自动允许
