# Claude Code v2.1.216 更新日志

> 🗓 2026-07-20 发布 · 📋 40 条更新（🚀 1 · 🔧 8 · 🐛 30 · 📌 1）

**✨ 本版亮点**

- 🚀 **新功能**：新增 sandbox.filesystem.disabled 设置，可关闭文件系统隔离同时保留网络出站控制
- 🐛 **关键修复**：修复长会话中消息规范化开销随轮次平方增长导致的数秒卡顿与恢复缓慢
- 🐛 **关键修复**：修复恢复后台 agent 会话时退回默认 agent，现已正确还原提示词与工具限制
- 🐛 **关键修复**：修复云端会话容器重启导致消息丢失，中断的回合现在恢复时自动重跑
- 🔧 **改进**：/rewind 不再经由符号链接或硬链接还原文件，并报告跳过的路径数

**🚀 新功能**（1 条）

- 新增 `sandbox.filesystem.disabled` 设置，可跳过文件系统隔离同时保留网络出站控制

**🔧 改进**（8 条）

- 改进 `/fork` 确认为单行显示，包含新会话名称、`claude attach` id，以及副本共享你的检出时的提示
- 改进 PowerShell 工具中对 `git` 和 `gh` 命令参数的验证
- 改进 `/ultrareview` 的 diff 过大错误提示，显示配置的限制、实际测量的 diff 大小以及贡献最大的文件
- 改进 `/code-review ultra` 的空 diff 消息，指明确切的 base ref 并建议显式传入 base
- 改进支出限额调整提示，在限额修改被拒绝时显示服务器的原因
- `/context` 现在在对话超出上下文窗口时显示明确警告，失败的 `/compact` 以错误形式显示
- 后台会话：当无客户端连接时，`/mcp` 和 `/install-github-app` 现在会在 agent 视图中挂起一个“需要输入”请求
- 更新内置 dataviz skill：重排默认图表调色板，并修复建议四系列图表使用直接标注的指引

- 修复长会话中的性能下降问题：消息规范化开销随轮次呈平方增长，导致数秒卡顿和恢复缓慢

- 修复 Claude Code on the web 在会话空闲几分钟后重复提问并丢失你的回答的问题
- 修复以下问题：文件修改类 hooks 之后 @-mentions 静默不附加任何内容、vim 中 `c` 操作符与粘贴的点重复、statusline 恢复时运行两次、恢复选择器失败时挂起
- 修复恢复的后台 agent 会话退回默认 agent 的问题：agent 的提示词和工具限制现在会被正确还原
- 修复 worktree 隔离的 subagent 通过 `git -C`、`--git-dir` 或 `GIT_DIR`/`GIT_WORK_TREE` 将 git 重定向到共享检出目录的问题
- 修复 worktree 会话在工作目录与所选项目不匹配时，落入其他项目遗留 worktree 的问题

- 修复 Bash 命令权限检查在 `&&` 列表或取反中包含重定向的复合语句时的问题
- 修复在 agent 列表中按两次 Ctrl+X 删除会话失败的问题，以及后台 worker 已死亡时已删除会话重新出现的问题
