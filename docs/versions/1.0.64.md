**✨ 本版亮点**

- 🚀 **新功能**：Agents 支持自定义模型，可为不同 agent 指定专属模型

- 🔧 **改进**：文件搜索与 @ 提及建议现包含隐藏文件
- 🐛 **关键修复**：修复 SDK 在多轮对话中用户输入追踪失效的问题
