# Claude Code v2.1.259 更新日志

> 🗓 2026-09-02 发布 · 📋 37 条更新（🚀 5 · 🔧 5 · 🔄 1 · 🐛 26）

**✨ 本版亮点**

- 🚀 **新功能**：新增 managedMcpServers 托管设置，组织可为所有用户统一提供 MCP 服务器
- 🚀 **新功能**：新增 --permission-prompts none，无人值守环境下需提示的权限自动拒绝
- 🐛 **关键修复**：修复并发会话互相覆盖 ~/.claude.json，工作区信任与 MCP 状态不再丢失
- 🐛 **关键修复**：修复 Bash Read() 拒绝规则可被选项参数等方式绕过的问题，安全更严密

**📋 更新明细**（共 37 条，按类别归组）

**🚀 新功能**（5 条）

- 新增 `managedMcpServers` 托管设置：组织可为所有用户提供 HTTP/SSE MCP 服务器（条目格式与 `.mcp.json` 相同）；指定了要运行命令的条目会被跳过
- 新增 `--permission-prompts none`，适用于无人值守的 headless 主机：任何需要提示的操作都会被自动拒绝，同时当前的权限模式（包括 auto 模式）仍继续生效
- 新增对 `glab mr create/merge/close/reopen/note/update` 的识别，GitLab 合并请求在折叠的工具摘要中会显示为 `MR !N`，并刷新底部 MR 徽标
- 为 `claude plugin validate` 新增 `--json` 参数，输出机器可读的验证报告
- [VSCode] 会话列表侧边栏新增 Active 快速筛选器和状态筛选菜单（Needs input、Working、Completed）

**🔧 改进**（5 条）

- 通过复用文本测量，改善长回复下终端缩放和首次渲染的性能
- 改进 `/workflows` agent 详情：JSON 结果会以语法着色和真实换行美化输出，过长结果折叠在展开开关之后
- 改进 headless/SDK 会话启动：MCP 服务器连接完成后，第一轮最多可提前 50 ms 开始
- 改进 `/install-github-app`：在 GitLab 仓库中运行时会说明其仅支持 GitHub，并指向 GitLab CI/CD 文档
- 改进嵌套后台 subagent 的结果保存到父 subagent 的转录中，因此恢复的 subagent 可保留它们，共享转录也会展示交付结果

**🔄 变更**（1 条）

- 变更 `allowedMcpServers` 仅管理用户添加的服务器：升级后，之前被白名单过滤掉的 `managed-mcp.json` 字面服务器现在会加载；如需禁用请使用 `deniedMcpServers`

**🐛 修复**（26 条）

- 修复并发会话静默回滚彼此对 `~/.claude.json` 的修改——同时运行多个会话时，工作区信任不再被重置，MCP/项目状态不再丢失
- 修复某个对话的 thinking 一旦被拒绝，后续每一轮都会再次被拒绝的问题
- 修复 Bash `Read()` 拒绝规则未覆盖作为选项值传入的文件（如 `--ignore-revs-file=.env`、`-f.env`、`@file`）、`git diff`/`git grep` 的文件操作数，以及 `cd DIR && cat FILE` 组合命令；`grep -r`/`cp -r` 遍历包含被拒文件的目录时现在会询问
- 修复在禁用遥测的会话中，OAuth token 刷新导致 prompt 缓存失效的问题
- 修复全屏模式下，包含数百次工具调用的长对话轮次结束后显示空白对话的问题
- 修复 auto 模式在命令或 skill 的 frontmatter `model:` 指定了不支持的模型时仍会在该模型上运行轮次的问题；现在轮次会保持会话模型
- 修复 `CLAUDE_CODE_MAX_CONTEXT_TOKENS` 对 Vertex 风格模型 ID（带 `@YYYYMMDD` 后缀）且模型版本 Claude Code 无法识别时被忽略的问题
- 修复运行中 shell 命令的实时输出预览在较早行发生换行时会隐藏最新行的问题
- 修复每次启动都会为 claude.ai 用户运行的后台 GitHub 连接检查；结果现在会跨启动记忆
- 修复保存的会话包含无 payload 的附件条目时 `--resume` 失败（且 `--continue` 打开空白对话）的问题
- 修复自定义命令和 skill 的 frontmatter `model:` 在交互式会话中被忽略的问题
- 修复从旧版本延续的对话中 Artifact 发布一次并报 "unexpected parameter `note`" 错误的问题
- 修复启动时当 MDM 配置的策略辅助程序或托管设置文件已运行过时，托管的 `forceRemoteSettingsRefresh` 被忽略的问题
- 修复 worktree 隔离在 `git rev-parse` 以"not a git repository"以外的消息失败时，拒绝 hook 创建的 worktree 的问题
- 修复云会话的 OpenTelemetry 指标和事件缺少 `user.email`、`organization.id` 和 `user.account_uuid` 属性的问题
- 修复 MCP 服务器在启动时列出工具期间断开连接后，显示为已连接但无工具而不是报告错误的问题
- 修复文件编辑权限对话框有时将变更行截断且无任何提示的问题
- 修复仓库检测在 git 探测瞬时失败后丢弃已知仓库身份的问题
- 修复托管设置文件、drop-in、MDM plist 或 HKLM 值无法解析时被静默忽略的问题：Claude Code 现在会拒绝启动并指出来源
- 修复远程控制会话中 Stop 未真正停止后台 agent 和工作流的问题：被终止的任务现在会保持可见且可重新停止，直到其进程退出
- 修复在上一个停止的运行仍在退出时恢复工作流运行，可能导致其 agent 重复运行的问题

- 修复阻塞性 Stop hooks 导致被阻止后的下一轮丢失该轮模型推理内容，且在部分模型上错失 prompt 缓存的问题
- 修复浏览器托管的 MCP 服务器页面关闭后，远程（claude.ai）会话需要 60 秒才能开始下一轮的问题
