# Claude Code v2.1.218 更新日志

> 🗓 2026-07-22 发布 · 📋 36 条更新（🚀 3 · 🔧 4 · 🔄 6 · 🐛 23）

**✨ 本版亮点**

- 🔧 **改进**：/code-review 改为后台 subagent 运行，审查结果不再挤占对话上下文
- 🐛 **关键修复**：修复 Windows 含 \u 前缀路径（如 C:\Users\unicorn）被误转成 CJK 字符导致文件无法访问
- 🐛 **关键修复**：修复左方向键误丢弃对话且无法撤销，现在会先确认，Esc 可返回后台对话
- 🔧 **改进**：auto 模式下危险命令等检查不再弹出权限对话框，由分类器自动裁决
- 🔧 **改进**：标记为 context: fork 的 skills 默认后台运行，可通过 background: false 退出

**📋 更新明细**（共 36 条，按类别归组）

**🚀 新功能**（3 条）

- 在 `--ax-screen-reader` 模式下，为单词和行删除操作（`Option+Delete`、`Ctrl+W`、`Cmd+Backspace`、`Ctrl+U`、`Ctrl+K`）添加了屏幕阅读器对被删除文本的播报
- 添加了通过 `/config model=<x>` 或 Remote Control 切换模型导致 fast 模式变化时的播报通知
- 为 skill 和插件 frontmatter 布尔值添加了 `yes`/`no`/`on`/`off`/`1`/`0`（不区分大小写）作为可接受值，与 `true`/`false` 并列

**🔧 改进**（4 条）

- 改进了 `/ultrareview` 的错误反馈，使 Claude 能够修正无效参数，而不是原样重试
- 改进了 auto 模式：危险 rm、后台 `&` 以及可疑 Windows 路径检查不再弹出权限对话框，改由 auto 模式分类器裁决
- 改进了针对 IDE 交互的沙箱命令限制
- 改进了信任对话框，现在会指明授权所覆盖的仓库根目录

**🔄 变更**（6 条）

- 将 `/code-review` 改为以后台 subagent 运行，审查工作不再占满你的对话，并保持将堆叠的斜杠命令作为审查目标
- 将 `/deep-research` 改为仅在手动调用时启动；Claude 不再自行启动它
- 将 auto 模式下的 plan mode 改为：对静态分析器无法证明只读的 Bash 命令不再弹出提示，改由 auto 模式分类器判断
- 更改了服务器管理的设置：良性功能和费用开关不再触发设置审批提示
- 将 agent markdown 文件改为拒绝包含 `:` 的 agent 名称，该符号保留给插件命名空间使用
- 将标记为 `context: fork` 的 skills 改为默认在后台运行；可通过每个 skill 的 `background: false` 退出

**🐛 修复**（23 条）

- 修复了工具输入中含 `\u` 前缀的 Windows 路径（如 `C:\Users\unicorn`）被错误转换成 CJK 字符，导致这些文件无法访问的问题
- 修复了左方向键直接丢弃对话且无法撤销的问题：编辑后立即按键现在会请求确认，agent 视图中的 Esc 会返回被转入后台的对话
- 修复了在将粘贴的换行符编码为 Ctrl+J 的终端中，多行粘贴被折叠为一行且换行变成 `j` 的问题
- 修复了从消息选择器执行 compact 后 `/context` 报告过期的压缩前 token 用量的问题
- 修复了 `/ultrareview` 在传入描述性参数（如 "review my auth changes"）时失败的问题——现在会对当前分支运行审查，并将该文本作为附注应用到审查结果中
- 修复了 `/code-review ultra` 在非交互式会话中静默运行本地审查的问题——现在会启动云端审查
- 修复了网关费用计量：Bedrock 应用推理配置文件 ARN 及其他配置映射的上游模型 ID，现在按所配置模型的费率计价
- 修复了长 IDE 选区在 emoji 中间被截断时出现乱码的问题，以及工具执行器错误可能被静默丢弃的一个问题
- 修复了引擎销毁竞态可能启动并遗留一个幽灵回合的问题，并使关闭后推送的输入被一致地拒绝
- 修复了工具调用被中断后出现虚假的 "[Request interrupted by user]" 消息，以及工具在响应中途中止时转录中遗留未配对的 `tool_use` 块的问题
- 修复了 `--ax-screen-reader` 模式下 VoiceOver 在输入末尾将键入的空格读成 "new line" 而非回显的问题
- 修复了插件和设置面板不将终端光标移动到聚焦行的问题，使屏幕阅读器和放大镜能够跟随方向键导航
- 修复了在删除或移动深度嵌套的被监控目录树时，以及渲染深度嵌套 UI 树时导致的崩溃（maximum call stack exceeded）
- 修复了会话在创建或关联 PR 后立即退出时，PR 事件偶尔丢失的问题
- 修复了 Bedrock 设置向导在分区 AWS 区域和使用 assume-role 配置文件时，以及在仅代理网络下配置文件验证失败的问题
- 修复了系统时钟调整后偶发的回合时长为负或不正确的问题，改用单调时钟为回合计时
- 修复了 "N MCP servers need authentication" 启动提示对未在 claude.ai 中连接的 claude.ai 连接器计数过多的问题
- 修复了历史记录写入发生竞争或失败时，提示历史条目丢失或重复的问题
- 修复了在大 thinking 预算下出现上下文溢出错误后，重试循环反复发送注定失败的相同请求的问题；`Ctrl+B` 后台化现在与其他路径应用相同的后台 shell 上限
- 修复了 agent frontmatter hooks 从不受信任的文件夹运行的问题：hooks 现在要求 agent 文件所在的文件夹已接受工作区信任
- 修复了 headless 和 SDK 会话中压缩后 fork-session 谱系丢失的问题
- 修复了会话历史中存在格式错误的增量附件时，恢复的会话每回合都失败或恢复时崩溃的问题
- 修复了远程会话在其 worker 被替换后仍持续发送心跳的问题，该问题导致长期运行的桌面和 IDE 进程每隔几秒永久重试一个被拒绝的请求
