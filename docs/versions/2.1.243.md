# Claude Code v2.1.243 更新日志

> 🗓 2026-08-24 发布 · 📋 60 条更新（🚀 10 · 🔧 13 · 🔄 4 · 🐛 33）

**✨ 本版亮点**

- 🔧 **改进**：原生安装与自动更新下载体积大幅缩减，Linux x64 从约 340 MB 降至约 75 MB，启动与内存占用同步优化
- 🚀 **新功能**：新增 modelPicker、promptCacheTtl、modelPricing 等设置，可自定义 /model 列表、延长缓存并用组织合同价计算成本
- 🚀 **新功能**：/login 支持无 API Key 的 Console 账号登录，方便禁止 API Key 的组织使用
- 🐛 **关键修复**：修复非交互与 SDK 会话中远程 MCP 服务器断连后永不恢复的问题，现可自动重连或明确报错
- 🐛 **关键修复**：修复 Anthropic API 无响应时会话卡住 10 分钟以上，现 3 分钟超时后重试并提示错误

**📋 更新明细**（共 60 条，按类别归组）

**🚀 新功能**（10 条）

- 为 /usage 新增 Loops 细分视图：每个 /loop 的运行次数、总 token 数、单次 token 数及最近一次运行，便于发现失控或话痨式的 /loop 任务
- 新增 modelPicker 设置：可用有序、带标签的模型列表定制 /model 选择器（支持任意 id 拼写，包括 Vertex/Bedrock id），可追加或替换内置列表
- 新增 promptCacheTtl 和 subagentPromptCacheTtl 设置，API Key 和云端服务商用户可将主对话的提示缓存保持 1 小时，同时子代理仍为 5 分钟
- 新增 modelPricing 托管设置，组织的合同定价和折扣系数将用于 /cost、状态栏及遥测成本数据，取代列表价
- 在 /login → Anthropic Console 下新增免 Key 登录方式："使用你的 Console 账号登录"（推荐），与创建 API Key 并列，禁止使用 API Key 的组织也可登录
- 在 /status 中新增 "Skipped sources" 一行，列出存在但未生效的托管设置来源（例如 managed-settings.json），因其被更高优先级的托管来源覆盖
- 在 /mcp 和 /plugins 中，为由组织管理身份验证的 claude.ai 连接器添加 managed 标记
- 为尚未在 Claude Code on the web 上连接 GitHub 的 claude.ai 用户新增提示，引导其使用 /web-setup
- 新增 /status 一行，显示 Claude Code on the web（Pro/Max）是否已连接 GitHub，未连接时会指向 /web-setup
- 在 /tasks 和代理详情对话框中显示每个子代理运行的模型（及 effort 等级）

**🔧 改进**（13 条）

- 提升启动速度：沙箱和 MCP 初始化不再阻塞首帧，裸启动跳过子命令注册，工作流发现、设置和信任库的开销更低
- 改善原生安装和自动更新的下载体积：二进制文件现采用 zstd 压缩（Linux x64 上约 75 MB，此前为 340 MB）
- 改进使用遥测向组织的归属，适用于直接使用 ANTHROPIC_AUTH_TOKEN 对接 Anthropic API 进行身份验证的会话，使组织的数据处理设置生效
- 改善原生二进制体积：以更紧凑的方式存储内置技能和提示文本，缩小约 2 MB
- 改善原生构建的内存占用：代码改为按需加载而非整包常驻（每个会话约节省 40–70 MB 内存）
- 改善长时间运行会话的峰值内存占用（运行时现在会随堆增长更早进行垃圾回收）
- 改进 SSH 下的 /login 体验：登录 URL 立即显示，按 c 会报告 URL 的复制方式而非总是声称成功，并有提示说明如何在全屏模式下选择文本
- 改进 effort 为 xhigh/max 且关闭 thinking 时的错误提示：现在会指明等级、禁用 thinking 的设置项，并给出 /effort high 作为修复方法
- 改进 /loop：Claude 无事可做的连续唤醒现在折叠为终端中的单行，而非逐条打印
- 更新 /model 选择器和内置 claude-api 技能，将 Sonnet 5 的每 Mtok $2/$10 定价作为标准列表价展示，而非限时促销价
- 改进恢复对话且其 Remote Control 被其他终端持有时提示：现在会说明其他机器上的会话无法被本机看到或联系到
- [VSCode] 改进长会话中的历史裁剪：优先丢弃较早的工具活动行，使你的消息和 Claude 的回复保持可见
- [VSCode] 改进使用 Claude 账号登录时扩展自身使用遥测向组织的归属，使组织的数据处理设置生效

**🔄 变更**（4 条）

- 变更沙箱 Bash 工具提示，不再列出允许的网络主机，让 Claude 尝试发起请求（你可批准新主机），而不是默认未列出的主机被阻止
- 变更 macOS 上的计算机使用行为：点击桌面、Dock 或 Finder 窗口需要像其他应用一样通过访问对话框授予 Finder 权限
- 变更 /model、/fast 和 /effort 在 Bedrock、Vertex、Foundry 上以及禁用遥测时，也改为立即执行而非排队等待回合结束
- 变更跨会话消息收件箱套接字，关闭 30 秒内未发送完整行的连接；向其提交数据的脚本应在数据就绪后再建立连接

**🐛 修复**（33 条）

- 修复非交互（-p）和 SDK 会话中的远程 MCP 服务器断连后永不恢复的问题；现在会自动重连或报告为失败
- 修复从桌面应用发起的 MCP 服务器登录在支持 client ID 元数据文档的服务器（例如 Linear）上报 "Invalid redirect URI" 失败的问题
- 修复 auto 模式在启动时因缓存了临时的服务端禁用且后续特性开关拉取失败而一直不可用的问题
- 修复 API 短暂过载并要求客户端重试时，auto 模式工具调用在等待约一分钟后被拒绝为 "temporarily unavailable" 的问题
- 修复 /model 选择器静默忽略 Ultracode 选择的问题；现在选择 Ultracode 会立即应用到当前会话
- 修复 /resume 只列出最近 50 个会话的问题；选择器现在会在滚动时加载更多
- 修复云端会话在回合中途重启后恢复时，将待处理的 hook 或后台任务通知重新作为提示词发送，而非正常的续接消息
- 修复 2.1.232 套接字目录加固后，用户命名空间和无根容器内跨会话消息静默失效的问题
- 修复悬停在容器之外的文本（例如 /login 中的登录 URL）在屏幕其他部分重绘时丢失前导列的问题
- 修复 spellcheck 不给紧跟在 emoji 之后输入的拼写错误单词加下划线的问题
- 修复后台子代理在最后一个后台 Bash 任务完成后未被唤醒的问题
- 修复 Anthropic API 迟迟不开始响应时会话静默 10 分钟以上的问题：请求现在约 3 分钟后超时并重试一次，然后显示 API Error: No response from API
- 修复身份验证、模型可用性等客户端生成的错误信息渲染得像模型输出而非错误行的问题
- 修复 CI 中的工作负载身份联合：同一任务中的多个进程共享已交换的 token，而不是重复交换一次性 token；交换被拒时会带着服务器消息快速失败
- 修复以登录开头的会话（例如 /logout 后首次启动）启动时不显示服务端管理的 companyAnnouncements 的问题
- 修复 hook 的 if 条件（如 Bash(cat *)）在命令包含 $() 或反引号命令替换且后跟更多参数时，对无关 Bash 命令误触发的问题
- 修复通过 --plugin-dir 同时加载两个插件时，使用 marketplace 字段声明的插件依赖无法解析的问题
- 修复 /reload-plugins 在最后一个 LSP 插件被禁用后仍保留 LSP 工具的问题；现在还会在会触发重读对话的 LSP 插件变更前发出警告
- 修复 --agents 静默忽略无效 JSON 或无效代理定义的问题；现在会像 --mcp-config 一样以明确错误退出
- 修复 ~/.claude.json 中存在无效 MCP 服务器条目时，/status 显示没有文件名的 "Found invalid entries in: ." 的问题
- 修复 /clear 将 /rename 设置的会话名称从提示栏移除的问题，尽管该名称已保留给新会话
- 修复 ~/.claude/history.jsonl 包含格式错误条目时 Ctrl+R 历史搜索和上箭头历史失效的问题
- 修复在使用修改键编码（modifyOtherKeys / kitty 协议）的终端中 Ctrl+[ 无法退出 vim INSERT 模式的问题
- 修复 localhost 已列入 NO_PROXY 但未列入小写 no_proxy 时，本地 IDE 连接仍被路由到 HTTPS_PROXY（且有时失败）的问题；现在两种大小写均生效
- 修复被阻止的命令仍以退出码 0 结束时（例如 curl 打印代理的 403 页面），沙箱网络违规详情从 Bash 工具结果中被丢弃的问题
- 修复窗口在会话空闲期间重置后，状态栏 rate_limits 字段和 /usage 仍显示该窗口重置前使用百分比的问题
- 修复 claude --teleport <session> 因未提交的更改直接退出的问题，现在会像会话选择器一样提供 stash 后继续的选项
- 修复 /web-setup 在旧版 GitHub CLI（不支持 gh auth token）已通过身份验证时反复要求登录的问题
- 修复 Claude in Chrome 在自动更新清理掉其初始化所用的版本后与 Claude Code 失去连接的问题；原生宿主现在通过稳定的 claude 启动器启动
- [VSCode] 修复在首次拉取特性开关前启动的会话（例如刚安装后）以默认权限模式打开而非 auto 模式或所配置默认模式的问题
- [VSCode] 修复 Focus 视图中你展开的分区在子代理工具活动期间自行折叠的问题
- 修复 claude remote-control 在服务器中途丢失环境时退出并使已连接的 Remote Control 会话搁置的问题；现在可以恢复
- 修复由 claude remote-control 提供服务的 Remote Control 会话在其停止并重启后偶尔卡住的问题，该问题影响无管理员或 owner 角色的 Team 和 Enterprise 成员
